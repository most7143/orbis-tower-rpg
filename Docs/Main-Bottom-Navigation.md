# 메인 공통 하단 탭

승인한 배치와 추가 피드백을 프로젝트에 적용했다. 기준 해상도는 1920×1080이다.

## 배치

- 탭 순서: 로비 / 캐릭터 / 성장 / 뽑기.
- 가시 높이 92px, 탭 사이 간격 0, 사각 모서리, 바닥 여백 0.
- 바의 실제 Rect는 1920×156이며 bottom-center 피벗 (0.5, 0), 위치 (0, -64)다. 불투명 배경은 캔버스 아래 64px까지 이어지고 가로 렌더러 크기는 4배로 넓혀 가장자리 투명 틈을 덮는다.
- 아이콘·글자·선택판은 기존 가시 영역의 위치를 유지한다. Bar 내부 기준 Y=32가 가시 영역 중앙이다.
- 원본 아이콘 S04 지도 / S01 캐릭터 / S13 별 / S12 상자를 사용한다. 글자는 이미지에 굽지 않고 Maple 엔진 텍스트를 사용한다.
- 좁은 화면은 `min(1920, 1080 × 화면비)` 폭 안에서 네 탭을 균등 배치한다. 실제 기기의 시스템 세이프 영역은 별도 기기 QA 대상이며, 하단 64px 연장은 해당 영역이 비쳐 보이지 않도록 두는 여유분이다.

## 레이어와 본문

`ui/MainNavUI.ui`는 네 페이지 밖의 독립 UIGroup이다. GroupOrder 25로 두고, 같은 번호였던 PetUI는 24로 정리했다. 오프라인 보상 26, 화면 페이드 27, 레벨업 28, 툴팁 29는 위에 표시된다.

캐릭터·성장·뽑기 루트는 승인 시안과 같은 13/15 등비 축소와 Y=72 위치를 사용한다. 성장의 별도 각인·은총·유물·펫 패널에도 같은 변환을 합성해 하단과 겹치지 않게 했다. UITransform의 저장용 `Scale`과 `UIScale`은 같은 값으로 유지한다.

로비 중앙의 기존 성장·캐릭터·뽑기 버튼은 바인딩 호환성을 유지한 채 숨긴다. 플레이·계정 정보·상단 재화와 개발용 스킬 테스트 버튼은 유지한다.

## 선택과 입력

- 회색 발판 4개는 고정이고, 선택 Sprite는 정확히 하나다.
- 선택 Sprite의 X만 0.36초 ease-out으로 이동한다. 선택판의 Y·크기·피벗은 고정한다.
- 목적 페이지를 한 번만 열며, 지나가는 탭의 페이지는 열지 않는다.
- 이동 도중 다른 탭을 누르면 현재 보간 위치에서 새 목적지까지 이동한다.
- 현재 선택된 탭은 `ButtonComponent.Enable=false`로 재클릭을 차단한다. 강조 배경과 글자 밝기는 유지한다. 선택 중인 탭에서 hover/pressed 연출도 다시 시작하지 않는다.
- 다른 탭으로 이동하면 이전 탭 입력을 다시 켠다. 선택되지 않은 탭의 Normal/Hover/Pressed/Disabled 상태는 별도로 처리한다.
- 콘텐츠 잠금은 기존 UnlockTable을 따른다. 성장의 열린 하위 탭이 없으면 성장 비활성, 뽑기는 CharGacha 해금 조건을 사용한다.
- 잠금이나 모달로 비활성인 탭은 글자·아이콘 알파 0.35와 입력 차단을 적용한다. 현재 선택이라 재클릭만 금지한 탭은 이 회색 처리를 하지 않는다.
- 확인·오프라인 보상·레벨업 모달이 표시되는 동안 탭 입력을 차단한다.
- 페이지의 X 닫기로 로비로 돌아오면 선택판도 로비 위치로 돌아간다. 로비 외 맵에서는 하단 바를 숨긴다.
