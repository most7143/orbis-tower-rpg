# 직업·캐릭터 개편 기준 문서 (사용자 확정 2026-11-22)

이 문서는 사용자와 대화로 확정한 내용만 적는다. 자료 조사·구현·테스트 에이전트는 이 문서를 최우선 기준으로 삼는다.
여기에 없는 세부 수치·배치는 자료 조사 에이전트가 단계별 요구사항 문서(`Docs/Job-Redesign/Phase-N-*.md`)에서 정한다.

## 1. 목표

- 정해진 메이플 직업들 안에서 3명 조합을 맞춰 탑을 오르는 게임.
- 아웃게임은 수집형 RPG처럼 캐릭터 뽑기·레벨업·전직·장비 강화로 구매욕과 만족감을 준다.
- 판 안은 로그라이크: 갈림길·돌파·마법의 서·장신구·여신·유물로 매 판 다르게.

## 2. 캐릭터 (직업)

- 처음에 **히어로·비숍·나이트로드** 3직업을 지급한다. 나머지(보우마스터·바이퍼, 이후 추가 직업)는 뽑기로 해금.
- 직업마다 **차수**가 있고, 전직하면 **이름이 바뀐다** (예: 검사 → 파이터 → 크루세이더 → 히어로 → 5차).
  - 히어로: 검사 → 파이터 → 크루세이더 → 히어로
  - 비숍: 매지션 → 클레릭 → 프리스트 → 비숍
  - 나이트로드: 로그 → 어쌔신 → 허밋 → 나이트로드
  - 보우마스터: 아처 → 헌터 → 레인저 → 보우마스터
  - 바이퍼: 해적 → 인파이터 → 버커니어 → 바이퍼
  - 5차 이름은 자료 조사에서 정한다 (예: "히어로 (5차)").
- **캐릭터 레벨 1~30 = 1~5차**. 레벨업은 매 레벨 기본 스탯(공격력·체력·방어력) 상승, 정해진 레벨에서 전직.
  - 전직 레벨 구간은 30레벨 안에 고르게 배치 (너무 촘촘하지 않게). 자료 조사에서 확정.
  - 레벨업 재화: **경험의 서** (소·중·대).
  - 전직 재료: **직업 전용 전직 카드** (그 직업 전용). **공용 전직 카드**로 대신할 수 있다 (가장 좋은 결과, 확률 최저).
  - 1~5차는 같은 방식(레벨 + 전직 카드).
- **각성 레벨 30~40 = 엔드 콘텐츠**.
  - 각성의 서(재화)로 각성 경험치를 올리고, 각성의 돌(아이템)과 다이아 등을 써서 **확률로** 각성 단계를 올린다.
  - 각성 단계가 오를 때마다 현재 가진 스킬이 하나씩 각성(강화·변화)한다. 스킬은 5개(일반 3 + 하이퍼 + 궁극기)이므로 5단계에 걸쳐 하나씩.
  - 각성은 뽑기로 얻지 않는다.

## 3. 스킬 (진화 방식, B안)

- 직업마다 **칸 6개**: 고유 패시브 1 + 일반 스킬 3(주력기·보조기·기술) + 하이퍼 1 + 궁극기 1.
- 칸 안의 스킬이 **차수에 따라 진화**한다.
  - 주력기: 1차 해금, 2차·4차에 진화
  - 보조기: 2차 해금, 3차에 진화
  - 기술: 3차 해금, 5차에 진화
  - 하이퍼: 4차 해금 (긴 쿨타임 자동 시전)
  - 궁극기: 5차 해금 (기본 공격·스킬 적중으로 게이지가 차면 자동 시전)
  - 고유 패시브: 차수마다 효과 추가. 기존 위기 자동 발동·확률 발동 스킬은 패시브 단계 효과로 흡수.
- **판 안 돌파는 칸에 붙는다** (진화해도 돌파가 이어짐).
- 직업별 진화표 (기존 스킬 사용):

| 직업 | 패시브 | 주력기 (1→2→4차) | 보조기 (2→3차) | 기술 (3→5차) | 하이퍼 | 궁극기 |
|---|---|---|---|---|---|---|
| 히어로 | 콤보 어택 | 슬래시 블러스트 → 브랜디쉬 → 레이징 블로우 | 인레이지 → 에픽 어드벤쳐 | 패닉 → 콤보 데스폴트 | 발할라 | 소드 오브 버닝 소울 |
| 비숍 | 성수 | 에너지 볼트 → 홀리 애로우 → 엔젤레이 | 어드밴스드 블레스 → 인피니티 | 샤이닝 레이 → 디바인 퍼니시먼트 | 헤븐즈 도어 | 엔젤 오브 제미니 |
| 나이트로드 | 표식 | 럭키 세븐 → 트리플 스로우 → 쿼드러플 스로우 | 드레인 → 쉐도우 파트너 | 써든레이드 → 풍마수리검 | 블리딩 톡신 | 다크로드의 비전서 |
| 보우마스터 | 강화 화살 | 애로우 블로우 → 애로우 봄 → 폭풍의 시 | 애로우 플래터 → 피닉스 | 애로우 일루전 → 실루엣 미라주 | 애로우 레인 | 잔영의 시 |
| 바이퍼 | 에너지 | 서머솔트 킥 → 백 스핀 블로우 → 데몰리션 | 트랜스폼 → 퓨리어스 차지 | 에너지 버스트 → 하울링 피스트 | 스티뮬레이트 | 리버레이트 넵투누스 |

- **삭제**: 스킬 뽑기, 스킬별 아웃게임 레벨·합성·장착 5칸, 판 안 레벨(스테이지 레벨업·레벨당 스탯·레벨업 회복), 판 안 스킬 카드(레벨업 카드). 돌파 카드·마법의 서는 유지.

## 4. 외형

- **차수 외형만** 쓴다 (장비 외형 사용 안 함).
- 매 차수 **전체 세트**를 바꾼다. 낮은 차수에는 망토 같은 일부 부위가 없을 수 있다.
- 메이플 아바타 아이템 중 비슷한 레벨대 세트로 묶어 넣는다 (에이전트가 먼저 골라 넣고 보고).

## 5. 뽑기와 재화

- 캐릭터 뽑기: **다이아**(아이콘 `81462aeb825b4660991cef05651271cf`) 100개에 1회. 상시 통합 뽑기 + 기간 픽업.
  - 결과: 경험의 서 소·중·대, 직업 전용 전직 카드, 공용 전직 카드(확률 최저).
  - 10연 뽑기는 직업 카드(전용 또는 공용) 최소 1장 보장.
  - 처음 얻는 직업 카드 = 그 캐릭터 해금.
  - 교환 포인트·천장·픽업 세부는 자료 조사에서 확정 (참고안: 1회 1점, 30점 = 원하는 직업 카드 1장).
- 유물 뽑기: **탑의 열쇠** (이미 구현). 재화는 캐릭터 뽑기와 분리.
- 다이아 획득: **층 첫 클리어**, **별 달성 보상 마지막 단계**. 지급량은 자료 조사에서 확정.

## 6. 장비 (직업별)

- **편성 칸(1~3)마다 5부위**: 무기·투구·갑옷·장갑·망토 (신발 칸 제거). 장비는 직업이 아니라 편성 칸에 붙고, 칸에 들어온 캐릭터가 그 칸의 장비 능력치를 받는다 (사용자 확정 2026-11-22, 직업별 25칸 안 폐기).
- **주문서 강화(기존) + 큐브 잠재능력 = 한 세트**. 잠재능력 계승은 넣지 않는다.
- 잠재능력: 등급(레어·에픽·유니크·레전더리 등)과 칸별 옵션 풀, 큐브로 재설정·확률 등급 상승.
- **상위 큐브는 비포/애프터 선택** 기능 (결과를 보고 이전 옵션과 둘 중 선택).
- 기존 주문서 강화는 유지. 밸런스 문제가 있으면 수치 조정 가능.
- 망토는 **공용 스킬 옵션만**: 주력기·보조기·기술·하이퍼·궁극기 피해, 궁극기 게이지 충전 등 어떤 직업에도 통하는 칸 기준 옵션. 직업 고유 옵션은 넣지 않는다 (사용자 확정).

## 7. 작업 원칙

- UI는 **기존 프로젝트 리소스로 최대한 단순하게** (Docs/UI-Design-System.md 준수).
- 사용자 검수 없이 90% 이상 만족할 수준까지 완성한다.
- 자료 조사 → 구현 → 테스트를 단계별로 반복하고, 큰 기능은 잘게 나눈다.
- 사용자에게 보이는 글(UI 문구, 문서)은 한국어.

## 8. 메소 재화 (사용자 확정 2026-11-22)

- **판 안 메소(은색)**: 판 안에서만 쓰는 기존 메소. 애니메이션 클립 `7b417b1a1b0b40469077a4a261b00cbf`, 아이콘은 그 두 번째 프레임 `6dc65c8e575f4a18a435dee1133942ca`.
- **금색 메소(아웃게임)**: 아이콘 `02a489cccff24a139a6c3582a5871f58`. **스테이지 클리어 시 지급**하는 계정 재화. 사용처: 슬롯 강화 비용.
- 아웃게임 화면에 보이는 재화는 크게 **메소(금색)·다이아** 두 가지.
- **슬롯 강화 비용 = 금색 메소** (사용자 확정): 강화마다 금색 메소 소모, 단계가 오를수록 비용 증가(수치는 구현 에이전트가 정해 표로).
- **주문서 = 확률 보정 아이템**으로 변경: 부위 무관 공용, 하급 +5%p · 중급 +10%p · 상급 +20%p, **강화 1회에 1장만**(선택). 주문서 없이도 기본 확률로 강화 가능. 실패 시 쌓이는 추가 확률은 유지. 기존 부위별·등급별 주문서 보유분은 같은 등급 공용 주문서로 합산.
- **스킬북 제거**: 스테이지 보상 아이콘·판 보상·결과 팝업·로비 표시에서 삭제. 저장값은 남기되 사용·표시 안 함.
- 금색 메소 지급: 스테이지 클리어마다 층 비례, 보스 스테이지는 더 많이. 디버그 판은 지급 안 함.

## 9. 펫 (사용자 지시 2026-11-22, 설계 진행 중)

- 성장창의 가장 안쪽 탭(예전 스킬 탭 자리)에 둔다.
- 등급: 레어 5종 · 에픽 5종 · 유니크 5종 · 레전더리 3종.
- 바로 구현하지 않는다. 펫 후보를 먼저 모아 사용자가 고른다.

## 10. 계정 레벨업 연출·보상·해금 (사용자 확정 2026-11-22)

- 계정 레벨업 시 화면 중앙에 가로 띠로 조금 크게 "레벨업!" 연출 + 레벨업 보상 지급(금색 메소·다이아).
- 계정 레벨로 해금되는 콘텐츠가 있으면 같은 연출에 "ㅁㅁ 해금!" 표시.
- 해금 레벨: Lv2 슬롯(장비 강화) · Lv3 각인 · Lv4 유물 · Lv5 캐릭터 뽑기 · Lv8 펫 · Lv15 은총 · Lv25 큐브(잠재능력).
- (메인 세션 결정) 보상: 레벨마다 금색 메소 100×새 레벨, 다이아 50(해금 레벨이면 다이아 100). 해금 전에는 해당 탭·버튼을 비활성 + "Lv.N 해금" 표시, 실제 입력·서버 요청도 차단. 이미 그 레벨 이상인 계정은 처음 접속 때 해금 상태로 시작하고, 지난 레벨 보상은 소급 지급하지 않음.
- 레벨업 연출은 저절로 사라지지 않고, 화면 아무 곳이나 클릭하면 닫힘(사용자 확정). 클릭은 연출만 닫고 아래 버튼은 동작하지 않음.
- 사용자 승인으로 PlayerEngrave CanEditRelic·CanEditGrace에 `_UnlockRules:IsOpen` 검사 추가(유물 Lv4, 은총 Lv15 서버 차단). 각인은 새 PlayerTalent에서 검사.
