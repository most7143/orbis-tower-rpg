# 계정 레벨 1~100 성장·보상 및 UI 기획

- 작성일: 2026-11-14
- 상태: 기획 문서. 계정 레벨·보상·관련 UI 구현 완료를 의미하지 않는다.
- 목적: 매 판 확정 경험치를 지급해 장기 성장 목표를 제공한다.
- 기존 기획: `StageSelect-Result-UI-Handoff.md`, `StageSelect-Result-UI-Implementation.md`와 함께 읽는다. 기존 화면은 다른 작업으로 변경될 수 있으므로 구현 전에 실제 파일을 확인한다.

## 1. 사용자 요청과 이번 문서의 해석

- 계정 레벨은 Lv1~100. 판 안 레벨과 별개이며 영구 저장한다.
- 층별 경험치를 차등 지급하고, 성공·실패에 따라 지급량을 구분한다.
- 일반 보상은 공격력·최대 체력·방어력·최대 마나만 사용한다.
- 5레벨 단위는 기존 게임의 특수 능력치, 10레벨 단위는 더 큰 특수 보상이다.
- 최신 요청: 일반 보상을 모두 모으면 약 3배 효과, 특수 보상은 직전 안의 2배 효율.
- **해석:** 일반 보상의 만렙 누적치는 각 능력치 기본값 대비 +200%(최종 3배). 특수 보상은 직전 표의 수치를 2배로 조정한다. 단순히 기존 일반 보상 숫자만 3배로 하는 의미가 아니다.
- **특수 보상 수치 2배와 실전 화력 2배는 다르다.** 발동·상한·합산·빌드에 따라 실제 효율은 달라지므로 밸런스 검증이 필요하다.

## 2. 일반 레벨 보상 — 전체 80회

| 끝자리 | 보상 | 횟수 | 만렙 누적 |
|---|---|---:|---:|
| 1·6 | 기본 공격력 +10% | 20회 | +200% |
| 2·7 | 기본 최대 체력 +10% | 20회 | +200% |
| 3·8 | 기본 방어력 +10% | 20회 | +200% |
| 4·9 | 기본 최대 마나 +10% | 20회 | +200% |

- 각 회차 증가량은 기준값의 10%를 합산한다. 레벨마다 1.1배씩 복리로 곱하지 않는다.
- Lv1에도 공격력 보상을 지급한다. Lv1부터 계산한 최종 누적은 기본값의 3배이며, Lv1 계정 대비 배율은 정확히 3배가 아니다.
- 최대 마나 기본값이 100이면 만렙 300. 마나 회복 속도·시작 마나는 자동 증가시키지 않는다.
- 계정 성장 적용 예: `계정 적용 기본 능력치 = 계정 보너스 제외 기본 능력치 × (1 + 계정 누적 증가율)`.
- 장비·각인·은총 등 다른 성장 항목까지 최종 3배가 된다는 뜻은 아니다. 구현 시 기본 능력치 산출 지점과 기존 보너스 합산 순서를 명시한다.
- 기본값이 0인 능력치는 비율 보너스만으로 증가하지 않는다. 모든 직업의 기본값을 확인한다.
- 계정 레벨 보상 때문에 판 안 카드·장비·빌드 선택이 무의미해지지 않도록 전투 테스트한다.

- 칭호·프로필 테두리는 선택적 기념 보상 제안이며 별도 확정 전 필수 보상으로 구현하지 않는다.

## 4. 1~100레벨 데이터 작성 규칙

1. 5의 배수는 §3의 특수 보상만 지급한다.
2. 나머지는 끝자리 기준 §2의 일반 보상을 지급한다.
3. 계정 초기 Lv1 보상을 포함하며, 중복 초기 지급을 방지한다.
4. 한 판에 여러 레벨이 오르면 지나간 모든 레벨의 효과를 반영한다.
5. 효과는 현재 계정 레벨과 보상 테이블에서 재산출하는 방식을 우선한다. 로그인할 때 다시 더해 능력치가 중복 증가하지 않도록 한다.

## 5. 층 경험치와 성공·실패 정산

직전 제안 유지. **100층을 경험치 보상 상한으로 보는 가정**이다. 현재 실제 데이터는 315층이므로 층 구조와 상한 정책은 구현 전에 조정해야 한다.

```text
클리어 EXP = 반올림(100 × 20^((층 번호 − 1) / 99))
실패·중단 EXP = 내림(해당 층 클리어 EXP × 0.5 × 완료 스테이지 수 / 전체 스테이지 수)
```

| 시점 | 예상 도달 층 | 클리어 EXP |
|---|---:|---:|
| 시작 | 1 | 100 |
| 1주 | 20 | 178 |
| 1개월 | 35 | 280 |
| 3개월 | 55 | 512 |
| 반년 | 70 | 807 |
| 1년 | 80 | 1,092 |
| 2년 | 90 | 1,478 |
| 3년 | 100 | 2,000 |

- 101층 이상을 위 식에 그대로 넣으면 2,000을 초과한다. 315층 존속 시 경험치 상한 적용 또는 전체 공식 재설계가 필요하며 아직 확정하지 않았다.
- 실패 시 아무 스테이지도 완료하지 못했으면 EXP 0.
- 별 미션과 계정 EXP는 분리한다. 별을 못 얻었다고 성공 EXP를 줄이지 않는다.
- 판 종료 시 서버에서 한 번만 정산한다. 결과창 재열기·중복 요청으로 추가 지급하지 않는다.
- 계정 EXP 획득량 증폭은 이번 레벨 보상에 포함하지 않는다.

## 6. 필요 경험치와 3년 기준

가정: 하루 20판, 성공률 80%, 실패 판 평균 진행도 50%. 위 도달 시점 사이의 층을 선형 보간하고 매일 당시 도달 층에서 플레이한다.

- Lv1→100 필요 총량: 약 **23,072,173 EXP**.
- Lv.L→L+1 필요량: `반올림(70.2670108 × L²)`, L=1~99.
- 실제 99개 필요량의 합계를 산출하고 마지막 단계에서 반올림 오차를 보정한다.
- 하루 20판·같은 도달 경로에서 약 1,095일. 매일 모든 판 성공하거나 상위층을 빨리 돌파하면 더 빨라진다.
- 강화된 보상이 실제 층 진행을 앞당길 수 있으므로, 3년은 보장 기간이 아닌 위 가정의 계산 목표다. 플레이 테스트 후 공급량·필요량을 함께 검증한다.

| 시점 | 예상 계정 레벨 |
|---|---:|
| 1주 | 약 9 |
| 1개월 | 약 16 |
| 3개월 | 약 28 |
| 반년 | 약 40 |
| 1년 | 약 57 |
| 2년 | 약 81 |
| 3년 | 100 |

계정 만렙은 장기 목표다. 일반 콘텐츠 대부분을 Lv100 달성 조건으로 잠그지 않는다. 무과금 1년 내 콘텐츠 80% 이상 경험이라는 게임 방향을 유지한다.

## 7. 계정 정보 UI 제안

### 7.1 진입점

- 메인화면 좌측 프로필 영역에 아바타·닉네임·계정 Lv·작은 EXP 바 배치.
- 프로필을 누르면 계정 정보 화면 진입. MSW 기본 좌측 상단 채팅·안내 영역을 피한다.
- 계정 레벨에는 항상 `계정`을 표시해 판 안 캐릭터 레벨과 구분한다.

### 7.2 화면 구조

```text
[← 메인으로]                계정 정보

[프로필·닉네임]        [계정 Lv57]   [현재 EXP / 다음 레벨 필요 EXP]
[칭호·테두리]         [================ EXP 바 ================]

[누적 성장 효과]                         [다음 성장 목표]
 공격력       +누적%                      Lv58  방어력 +10%
 최대 체력    +누적%                      Lv60  보스·엘리트 피해 +16%
 방어력       +누적%                            치명타 피해 +10%p
 최대 마나    +누적%                      [앞으로 N레벨]
 [특수 능력치 펼치기]

[성장 보상 로드맵 — 가로 스크롤]
  50 완료 ─ 55 완료 ─ 현재 57 ─ 60 주요 보상 ─ 65 ─ 70 … 100
  [레벨 선택 시 해당 레벨의 추가 효과 표시]

[계정 기록]
 최고 클리어 층 / 누적 별 / 누적 완료 판 / 누적 도전 판
```

- 기본 정보와 다음 목표를 처음부터 보여준다. 특수 능력치 전체 목록은 펼쳐서 확인한다.
- `계정 레벨로 얻은 효과`와 캐릭터의 `최종 전투 능력치`를 구분한다. 계정 화면의 +200%를 전체 장비 포함 최종 수치 3배라고 표현하지 않는다.
- 보상 로드맵은 5레벨 간격을 주요 노드로, 일반 레벨은 작은 눈금으로 표시한다. 선택하면 일반 레벨도 확인할 수 있다.
- 획득 보너스는 자동 적용이다. 매 레벨 수령 버튼을 눌러야 능력치가 생기는 흐름은 만들지 않는다.
- Lv100은 `MAX`와 누적 효과를 표시한다. 이후 EXP 저장·초과 EXP 정책은 별도 결정 전 임의 추가하지 않는다.

### 7.3 결과 화면 연결

기존 결과창에 계정 성장 블록을 추가한다.

```text
계정 성장                       획득 EXP +807
계정 Lv39  [==========================]  → Lv40

LEVEL UP · Lv40
받는 피해 −4% / 보스·엘리트 피해 +10%
다음 주요 보상: Lv45 첫 타격 피해 +10%
```

- EXP 바 증가 → 레벨업 표시 → 새 효과 순서. 일반 레벨은 짧게, 5·10레벨은 강조한다.
- 여러 레벨 상승은 한 번의 연출로 합산하고 상세 내역을 펼칠 수 있게 한다.
- 실패·포기 결과에도 획득 EXP와 바 증가를 보여준다. 0 EXP는 증가 연출 없이 이유를 표시한다.
- 보상 연출은 서버 정산 결과를 재생할 뿐 실제 지급 처리를 하지 않는다.
- 연출 스킵과 결과창 닫기 이후에도 지급 상태는 유지한다.

### 7.4 스테이지 선택 화면 연결

- 선택한 층의 상세에 `클리어 시 계정 EXP +N`을 표시한다.
- 실패 EXP는 `완료 스테이지에 비례 지급` 안내를 보조 설명으로 둔다.
- 미확정 성공 확률·권장 계정 레벨을 임의 표시하지 않는다.

## 8. UI 스타일과 구현 시 확인

- 최근 메인화면·직업선택의 금색·크림색 프레임, 파랑 주요 버튼, 보라 보조 영역을 참고한다.
- 계정 EXP는 별 보상과 구별되는 청록 계열, 5·10레벨 노드는 금색 강조를 제안한다. 색은 디자인 검토 후 조정 가능하다.
- 주요 수치는 모바일에서도 읽히게, 프로필 진입 버튼은 충분한 터치 영역을 확보한다.
- `.ui`는 UIBuilder로 조회·수정한다. 프로퍼티 바인딩은 실제 엔티티 UUID를 주입한다.
- 서버 저장·계정 데이터 로딩·판 정산은 기존 PlayerEngrave/TowerRunManager 경로와 충돌하지 않게 확장한다. 세부 구현 구조는 실제 파일 확인 후 결정한다.
- 데이터 로딩 실패 시 Lv1 기본값으로 저장 데이터를 덮어쓰지 않는다.
- UI 검증: 계정/판 안 레벨 구분, EXP0, 복수 레벨 상승, 5·10레벨 도달, 만렙, 미접속 재접속, 중복 정산 방지, 레벨 보너스 중복 적용 방지.
