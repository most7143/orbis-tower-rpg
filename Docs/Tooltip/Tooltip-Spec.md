# 툴팁 시스템 기준 (사용자 확정 2026-11-22)

## 사용자 규칙
1. 툴팁은 어떤 경우에도 **1개만**, **가장 최상단**에 보인다. 새 툴팁을 열면 이전 것은 닫힌다.
2. 종류·크기·내용이 다르다.
   - 글자: 단순 설명만 (폭 고정, 높이는 글 길이에 맞춤)
   - 아이템 목록: 보상 상자 등 — 획득 가능 아이템 **아이콘만** 칸으로 나열 (제목 1줄)
   - 스킬 상세: 인게임 스킬 — 아이콘·이름·칸 종류·쿨타임·설명·붙은 돌파 목록 등 상세 정보
3. 툴팁은 **절대 화면 밖으로 나가지 않는다** (위치 보정). 오른쪽 위 시스템 버튼 금지 영역(x≥740, y≥410)에도 걸리지 않게.
4. 툴팁이 떠 있을 때 **화면의 다른 곳을 누르면 사라진다.**

## 결정
- 다른 곳 클릭은 **닫기만** 한다: 그 클릭은 아래 버튼을 동작시키지 않는다(전체 화면 투명 입력 차단 판으로 흡수).
- 같은 대상을 다시 누르면 닫힌다. 다른 툴팁 대상을 누르면 그 툴팁으로 바로 바뀐다.
- 전투 중 스킬 툴팁을 열어도 **전투는 계속** 진행한다.
- 위치: 누른 요소의 위쪽에 띄우고 공간이 모자라면 아래쪽. 가로는 요소 가운데 기준으로 두고 화면 안으로 밀어 넣는다.
- 구조: 툴팁 전용 화면 파일(최상단 정렬) + `@Logic` 하나(`TooltipLogic`)로 모은다. 어느 화면이든 같은 호출(예: ShowText / ShowItems / ShowSkill(대상 엔티티, 데이터))로 연다.
- 디자인은 Docs/UI-Design-System.md 공통 골조(검정·차콜 외곽 + 밝은 내부)를 따른다.

## 1차 적용 대상
- 지역 선택: 클리어 보상·획득 가능 아이템(글자 툴팁: 이름·설명), 구간별 별 보상 상자(아이템 목록 툴팁)
- 전투 HUD 스킬 칸(스킬 상세 툴팁)
- 이후 설명이 필요한 곳에 같은 방식으로 확장

## 사용법 (구현 2026-11-22)
- 파일: 화면 `ui/TooltipUI`(그룹 정렬 30, 모든 화면 위) + `RootDesk/MyDesk/Tooltip/TooltipLogic.mlua`(`@Logic`, 클라이언트 전용).
- 호출(클라이언트 코드에서):
  - `_TooltipLogic:ShowText(대상엔티티, "제목", "설명")` — 폭 440 고정, 높이는 설명 길이에 맞춤.
  - `_TooltipLogic:ShowItems(대상엔티티, "제목", { 아이콘RUID, ... })` — 아이콘 칸만 나열(한 줄 6칸, 최대 12칸).
  - `_TooltipLogic:ShowSkill(대상엔티티, { icon=, name=, kind="주력기", cooldown=5, cooldownText=(선택, 쿨타임 대신 문구), desc=, breaks={ "이름 — 설명", ... } })`
  - `_TooltipLogic:Hide()` / `_TooltipLogic:IsShowing(대상 또는 nil)`
- 대상 등록: `_TooltipLogic:Register(대상엔티티, function() ...Show... end)`. 툴팁이 떠 있으면 전체 화면 투명 판이 입력을 먼저 받는다. 이때 누른 위치가 등록된 다른 대상 위면 그 함수로 바로 교체하고, 같은 대상이면 닫고, 그 밖이면 닫기만 한다(아래 버튼은 동작하지 않음). 등록하지 않은 대상은 툴팁이 떠 있는 동안 한 번 더 눌러야 열린다.
- 대상에 누름 입력 붙이기: 장식용 스프라이트는 빌더로 `RaycastTarget: true` + `ButtonComponent`(Transition 0=None)를 추가하고 `ButtonClickEvent`에서 Show를 부른다. 이미 다른 동작이 있는 버튼은 상태에 따라 나눈다(예: 지역 선택 별 상자 — 수령 가능하면 클릭 수령, 버튼이 꺼진 상자는 `UITouchDownEvent`로 툴팁).
- 위치: 대상 사각형(월드 모서리 → 툴팁 루트 좌표)의 위쪽, 모자라면 아래쪽. 가로는 대상 가운데에서 화면 안(여백 10)으로 밀고, 오른쪽 위 금지 영역(화면 오른쪽 끝 220·위쪽 끝 130 안)과 겹치면 왼쪽 또는 아래로 덜 움직이는 쪽으로 민다.
- 대상이 숨겨지거나 사라지면(화면 닫힘·맵 이동) 툴팁도 자동으로 닫힌다.
- 1차 적용: 전투 HUD 구성원 스킬 칸(`BattleHUDLogic.ShowSlotTip`), 지역 선택 보상 아이콘·별 상자(`RegionSelectLogic.ConnectTooltips`).

## 1차 구현 후 결정
1. 스킬 칸·보상 아이콘처럼 정보만 보는 칸은 상태 이미지 없이 Transition None으로 둔다(버튼이 아님).
2. 툴팁이 떠 있을 때 등록하지 않은 대상은 한 번 더 눌러야 동작한다(사양대로 닫기만).
3. 기존 장신구 칸 호버 툴팁(AccessoryHUDLogic AccTip)은 다음 작업에서 TooltipLogic으로 옮긴다.
4. 스킬석·메소 표시는 판 진행 중 계속 보인다(돌파·마법의 서 선택 때도 스킬석 수가 필요).
