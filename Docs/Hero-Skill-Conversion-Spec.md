# 히어로 스킬 변환 규칙서 — 원작 XML → 오르비스탑 스킬 데이터

- 작성일: 2026-11-17
- 목적: 원작(메이플스토리) 직업 XML만 넣으면 우리 게임용 직업이 만들어지는 **스킬 툴**을 만들기 위한 기준 문서. 첫 사례인 히어로를 기준으로, 원작에서 무엇을 빼고 무엇을 어떻게 바꿨는지 정리한다.
- 상태: 현재 프로젝트 데이터·코드(2026-11-17 기준)를 그대로 정리한 것. 새로 정한 규칙은 없다.
- 다음 직업: 팔라딘·다크나이트도 같은 형식의 문서를 하나씩 만든 뒤, 세 직업에 공통인 부분을 툴 규칙으로, 직업별로 다른 부분을 "직업 특수 규칙"으로 나눈다.
- **역할 (2026-11-18 추가):** 히어로는 **근거리 범위 딜러(전열)**다. 전담 탱커가 아니다. 역할·멀티·2인 편성 규칙은 §12와 [Job-Roles-Multiplayer.md](Job-Roles-Multiplayer.md), [Solo-Duo-Combat-Design.md](Solo-Duo-Combat-Design.md)에 있다. §12는 **아직 구현하지 않은 조정안**이고, §1~§11은 현재 구현 그대로다.
- 이전 설계안 `Hero-Skill-Star-Breakthrough.md`(11-03)는 **확률 발동 중심의 옛 초안**이다. 지금 구현과 다른 곳이 많으므로 이 문서와 실제 표가 우선한다. 차이는 §10에 모았다.

## 2. 원작 XML에서 읽을 것

### 2.1 지금 가지고 있는 원본

| 파일 | 내용 | 상태 |
|---|---|---|
| `~/Downloads/XML/String/String.xml` → `Skill.img` | 스킬 ID별 `name`, `desc`(설명), `h`(수치 문장 틀: `#damage`, `#mpCon`, `#attackCount`, `#mobCount`, `#cooltime`, `#time`, `#prop`, `#x`, `#y` 등) | **있음** |

## 3. 전투에서 스킬이 나가는 방식 (원작과 가장 큰 차이)

원작은 플레이어가 키를 누른다. 우리 게임은 **기본 공격이 몬스터에게 맞는 순간**에 그 공격에 함께 나갈 스킬을 고른다 (`HeroCombatLogic.RollCasts`).

1. 기본 공격 적중 → 콤보 획득 판정(30%), 마나 +2.
2. 동작 없는 효과는 항상 함께 나간다: 콤보 인스팅트 발동 판정, 인스팅트 지속 중 균열.
3. **캐릭터 동작이 있는 스킬은 공격 1회에 1개만.** 우선순위:
   1. 특수 우선 시전: 콤보 데스폴트 돌파 2, 코마 돌파 4 (최대 콤보일 때)
   2. 쿨타임형(`Trigger=Cooldown`) 중 쿨타임이 끝난 첫 스킬 (장착 순서). 인레이지(H05)는 따로 자동 발동하므로 제외
   3. 공격 스킬(`Trigger=Skill`) 중 쿨타임이 끝났고 마나가 되는 스킬 가운데 **마나 비용이 가장 큰 것**
4. 못 나간 스킬은 자원을 쓰지 않고 다음 공격에 다시 노린다.
5. 콤보를 쓰지 않는 직접 공격 스킬은 **타수마다** 30% 콤보 판정.
6. 다음 기본 공격은 이번 스킬 동작이 끝날 때까지 기다린다.

**원작에서 뺀 규칙:** 키다운·홀드, 공격 중 이동, 스킬 캔슬, 연계 입력(커맨드), 후딜 캔슬, 쿨타임 감소 모자, 버프 지속 증가 링크 스킬.

**툴이 정해야 할 값:** 각 스킬의 `Trigger`(Skill/Cooldown/Instinct)와 `ProcType`. 원작의 `cooltime`이 있고 MP를 쓰는 공격기는 Skill, 버프·소환은 Cooldown이 기본이다.

## 4. 자원·공통 규칙

### 4.1 마나 (원작 MP 대체)

| 값 | 기본 | 위치 |
|---|---|---|
| 최대 | 100 (계정 레벨 보너스 `AccountMana`% 적용) | `HeroCombatLogic.ManaMax` |
| 시작 | 30 | `ManaStart` |
| 초당 회복 | 5 | `ManaRegen` |
| 기본 공격 적중 | +2 | `ManaPerHit` |

- 원작 `mpCon`은 직접 쓰지 않는다. 우리 마나 비용은 **스킬 강도 순서**로 다시 정했다 (8 ~ 100).
- 카드 선택·몬스터 교체 중에는 회복이 멈춘다.

### 4.2 콤보 (원작 콤보 카운터 대체)

| 규칙 | 원작 | 우리 |
|---|---|---|
| 해금 | 2차 패시브 자동 | 아웃게임 콤보 어택 Lv.1 이상 (최대 Lv.11, 스킬북으로 올림) |
| 획득 | 공격마다 prop% (어드밴스드 콤보는 2개 충전 확률) | 콤보를 쓰지 않는 직접 공격 **타수마다 30%**로 1개. 2개 충전 없음 |
| 최대 | 10 (어드밴스드) | **5**. 코마 돌파 3 → 10, 콤보 데스폴트 돌파 5 → 15 |
| 효과 | 콤보당 최종 데미지 % | 콤보당 **기본 공격력 +(1 + 0.2×(레벨-1))%** — 모든 타격에 적용 |
| 감소 | 시간 지나면 감소 | **자연 감소 없음**. 소비 스킬로만 줄어듦 |
| 표시 | 캐릭터 주위 구슬 | 1~5개 콤보 아이콘, 6~10 어드밴스드, 11~15 슈퍼 아이콘 |

### 4.3 상태 이상 (`DebuffTable`)

| Id | 이름 | 효과 | 쓰는 스킬 |
|---|---|---|---|
| Darkness | 암흑 | 몬스터 공격 80% 빗나감, 5초 | 패닉 돌파 1 |
| Bleed | 자상 | 중첩당 몬스터가 받는 피해 +5% (방어력 감소), 6초, 최대 10중첩 | 여러 돌파 ('흉터') |
| Burn | 화상 | 1초마다 공격력 40%, 5초 | 레이지 업라이징 돌파 5 |
| IncisingBurn | 화상(인사이징) | 1초마다 공격력 20%, 5초 | 인사이징 기본 |

- 원작 자상(스카링 소드)은 지속 피해였지만 **우리 자상은 방어력 감소**다.
- 상태 이상은 맞은 몬스터마다 확률(`Chance`)로 따로 걸린다 (줄 선 몬스터 포함).
- 비슷한 효과의 돌파는 같은 이름을 쓴다: 자상 부여 = **'흉터'**.

### 4.4 피해 공식 (`HeroCombatLogic.Strike`)

```
기본값 = 판 공격력 × 스킬 계수(Pct)% × 아웃게임 레벨 배율
아웃게임 레벨 배율 = 1 + (레벨 - 1) × 0.2        (Lv.1 = 1배, Lv.11 = 3배)
배율 = (1 + (별 위력 + 돌파 보너스)%) × (1 + 모든 피해%) × (1 + 콤보 공격력%) × (1 + 자상 피해 증가%)
치명타 확률 = 판 치명타 + 별 치명 / 치명타 피해 = 판 치명 피해 + 별 치명 × 2
```

- 원작의 최종 데미지·보스 데미지·방어율 무시·일반 몬스터 추가 피해(`nbdR`)·속성 내성은 쓰지 않는다. 엘리트 추가 피해는 계정 보너스 `EliteDmg`로만 있다.

## 5. 성장 구조

### 5.1 아웃게임 (로비)

| 항목 | 규칙 | 위치 |
|---|---|---|
| 획득 | 스킬 뽑기. 등급별 확률 `SkillGradeTable` (1차 30% · 2차 25% · 3차 20% · 4차 15% · 하이퍼 7% · 5차 3%) | `GachaUILogic`, `PlayerEngrave` |
| 시작 지급 | 1~5번 (`SkillStartCount` 5) | |
| 합성 | 같은 스킬 3개 → 등급표 확률로 한 등급 위 스킬, 실패 시 같은 등급 | `RequestSkillSynth` |
| 레벨업 | 스킬북 (레벨 × 5)개, 최대 Lv.11 | `RequestSkillUpgrade` |
| 장착 | 5칸 (해제 없음, 교체만) | `RequestSkillEquip` |
| 콤보 어택 | 스킬북으로 Lv.0 → 11 | `ComboAttackLv` |

- 원작 SP·마스터리북·스킬 코어(V매트릭스) 강화는 모두 이 구조로 대체했다.
- 등급(`Grade`)은 원작 전직 차수를 그대로 쓴다: 1차·2차·3차·4차·하이퍼·5차(6차 소드 일루전도 5차 등급).

### 5.2 판 안 (레벨업 카드)

- 판을 시작하면 장착 5종 모두 **Lv.0(안 배움)**. 스킬 칸에도 안 보이고 발동하지 않는다.
- 레벨업할 때마다 카드 3장 중 1장 선택 (`RollChoices`, `RollCardOption`).
- 스킬 하나의 레벨 진행 (최대 Lv.9):

| 다음 레벨 | 카드 종류 |
|---|---|
| 1 | 습득 |
| 3, 6, 9 | 돌파 (남은 돌파 중 3개 제시 → 1개 선택) |

## 9. 스킬 툴 설계안

### 9.1 입력

1. 직업 지정: 원작 직업 코드 목록 (히어로 = 100, 110, 111, 112, 하이퍼, 5차 4000110xx).
2. String.xml `Skill.img` (이름·설명·수치 문장).
3. Skill.wz 직업 img XML (**추출 필요**): 레벨별 수치, `action`, `effect`, `hit`, `ball`, `icon`.
4. 사람이 채우는 설정 파일 (직업당 1개):
   - 고를 15종과 순서·등급
   - 고유 패시브 정의 (히어로 = 콤보)
   - 각 스킬의 Trigger·ProcType·SkillType 덮어쓰기
   - 수치 조정 계수 (아래 9.3)

### 9.2 출력

- `JobSkillTable` 행 15개, `HeroSkillTable`(→ 직업별 `XxxSkillTable`) 행 15개, `SkillActionTable` 행 15개, `SkillBreakTable` 행 75~76개.
- 업로드할 이펙트·아이콘 목록과 업로드 후 RUID 연결.
- 직업 특수 규칙 목록 (코드 작업이 필요한 돌파·스킬) — 자동 생성 불가 항목 보고서.

### 9.3 수치 변환 규칙 (히어로 값에서 거꾸로 추정한 초안)

| 값 | 변환 |
|---|---|
| 타수 | 원작 `attackCount` (최대 6). 다단(8타 이상)은 6 이하로 줄이고 계수를 올림 |
| 계수 | 원작 `damage × attackCount` 총합을 등급별 목표 총 계수에 맞춰 나눔. 히어로 총 계수: 1차 120, 2차 220, 3차 260~420, 4차 180~270, 하이퍼 650, 5차 750~1020 |
| 마나 | 등급·쿨타임 순서로 8 / 10 / 12~25 / 20 / 50~100 |
| 쿨타임 | 일반 공격기 5~7초, 강공격 10~12초, 하이퍼·5차 20~30초 |
| 버프 지속 | 10초 (소환 20초) |
| 대상 수 | 원작 `mobCount`: 1 → 1, 2~6 → 2~3, 7 이상 → 4 |
| 발동 방식 | MP 소비 + 공격 → Skill / 버프·소환 → Cooldown / 조건 자동 → Instinct |

> 위 표는 현재 히어로 값을 설명하기 위한 초안이다. 팔라딘·다크나이트 정리 후 공통 규칙으로 확정한다.

### 9.4 툴을 만들기 전에 할 일

1. **Skill.wz 직업 img 재추출** (지금 XML에는 직업 스킬 본문이 없음).
2. 돌파 효과를 §8.1 공통 유형으로 표에서 읽도록 `HeroCombatLogic`을 일반화 (`Has(id, n)` 하드코딩 → 효과 유형 + 수치).
3. `HeroSkillTable`과 `JobSkillTable`의 중복 열 정리 (한쪽에서 생성).
4. `HeroCombatLogic`(히어로 전용 전투 로직)을 직업 공통 + 직업 특수 규칙 모듈로 나누기.
5. 팔라딘·다크나이트 같은 형식의 문서 작성 → 공통/특수 확정.

## 12. 역할·멀티·2인 편성 조정안 (미구현)

2026-11-18에 정했다. 직업 공통 규칙은 [Job-Roles-Multiplayer.md](Job-Roles-Multiplayer.md), 2인 편성은 [Solo-Duo-Combat-Design.md](Solo-Duo-Combat-Design.md)가 기준이다. 아래는 히어로에 해당하는 부분만 모은 것이다.

### 12.1 역할

| 항목 | 내용 |
|---|---|
| 역할 | **근거리 범위 딜러 (전열)**. 앞에 서서 여러 마리를 베고 콤보를 터트린다 |
| 전담 탱커인가 | 아니다. 도발이 없고, 앞에 서서 맞는 만큼만 조금 단단하다 |
| 다른 딜러와 차이 | 나이트로드는 원거리 단일 딜러. 히어로는 대상 3~4 스킬이 많은 범위 딜러 |
| 팀에 주는 것 | 자상('흉터')으로 대상이 받는 피해 증가, 코마·패닉으로 기절·암흑, 졸개 정리 |

### 12.2 직업 기본 보정

| 항목 | 현재 | 조정안 |
|---|---|---|
| 체력 | ×1 | ×1.15 |
| 범위 보정 | 없음 | 2마리 이상 맞히는 공격의 피해 +10% |
| 위협 배율 | 없음 | ×1.5. 근거리에 있으면 위협 +50% (공통 규칙). 그래서 대개 히어로가 몬스터의 기본 공격을 받는다 |

### 12.3 효과 대상 열

- 모든 효과에 `Target`(Self / Party / LowestAlly / Enemy)을 붙인다.
- 히어로의 기존 효과는 모두 **Self 또는 Enemy**다. 파티 대상 효과는 아래 돌파 하나뿐이다.
- 자상·기절·암흑은 몬스터에 걸리므로, 2인 편성·멀티에서는 자연히 동료도 덕을 본다.

### 12.4 2인 편성·멀티용 6번째 돌파 (스킬당 최대 6개 규칙 사용)

| ID | 이름 | 효과 | Target | 유형 |
|---|---|---|---|---|
| H04_B6 | 제압 | 코마로 기절시킨 대상이 4초간 받는 피해 +15% | Enemy | ApplyDebuff |
| H08_B6 | 휩쓸기 | 레이징 블로우가 3마리 이상 맞히면 쿨타임 2초 감소 | Self | 특수 |
| H09_B6 | 정면 돌파 | 레이지 업라이징 시전 후 3초간 받는 피해 -30% | Self | BuffValue |
| H11_B6 | 전장의 기세 | 에픽 어드벤쳐 시전 시 파티 공격력 +10% (10초) | Party | BuffValue |
| H13_B6 | 끝장 | 콤보 데스폴트가 맞힌 대상에게 자상 5중첩 | Enemy | ApplyDebuff |

- 기존 76종 돌파와 솔로 수치는 바꾸지 않는다.
- 파티 지원 돌파는 H11_B6 하나다. 히어로가 서포터가 되지 않게 했다.

### 12.5 툴 반영

- 직업 설정 파일에 `Role`(MeleeAoE / Care / SingleTarget), 직업 보정(체력·범위·단일·회복·위협) 열을 추가한다.
- 돌파 표에 `Target` 열을 추가한다.
- §9.4 "툴을 만들기 전에 할 일"에 더한다: **전투 로직을 캐릭터 1명 기준에서 캐릭터 여러 명 기준으로 바꾸기** (2인 편성 대비).
