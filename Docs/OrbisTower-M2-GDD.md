## 1. 한 줄 컨셉
> "탑을 오르며 특정 조건을 달성하면 유물이 해금되고, 져도 판마다 쌓이는 '탑의 조각'으로 유물을 최대 15레벨까지 강화해 영구히 강해지며(실패할수록 확률이 올라 언젠가는 전부 만렙), 판 안에서는 터지는 뽑기 연출·천장·황금 몬스터와 보스 뒤 갈림길로 '한 판 더'를 만드는 마일스톤."

## 3. 핵심 루프
```
[로비] 탑의 조각 확인 → 유물 강화(성공/실패, 실패하면 다음 확률↑) → 탑 입장
  ↓
[판] 1층부터 자동전투 → 직업 카드(뒤집기 연출·천장) / 장비·스킬 강화
     → 가끔 황금 몬스터(잭팟) → 층 보스 처치 → 거래 → 갈림길 2택(보물방 / 시련방)
     → 조건 달성 시 "유물 해금!" 배너 (예: 처음으로 10층 도달 → 가죽 장갑 해금)
  ↓
[패배·중단] 정산 화면: 도달 층·처치 수·최고 데미지 + 탑의 조각·깃털·심볼 획득 + 새로 해금된 유물
  ↓
[로비] 조각이 쌓여 있음 → 유물 강화 → 한 판 더
```

## 4. 핵심 시스템

### A. 유물 (아웃게임) — M2의 중심
- **해금**: 유물마다 해금 조건이 하나씩 있음. 판 안에서 조건을 달성하는 순간 해금되고, 전투 화면에 "유물 해금!" 배너 + 효과음. 해금된 유물은 Lv1부터 바로 효과가 적용됨(다음 판부터).
- **해금 조건 종류**: 누적형(몬스터 누적 처치 N, 누적 메소 N), 기록형(처음으로 N층 도달, 보스 첫 처치), 순간형(체력 10% 이하에서 몬스터 처치, 한 방에 N 데미지), 플레이형(악마 거래 N회, 4차 전직 첫 달성), 패배형(처음으로 패배).
- **조건 진행도**: 잠긴 유물은 실루엣 + 해금 조건 + 진행도 바(예: 몬스터 처치 63/100)를 보여줌 → "이것만 하면 열린다"는 다음 목표 역할. 로드맵 Backlog의 '업적'을 일부 대신함.
- **강화**: 탑의 조각을 써서 레벨 +1. 최대 **Lv15**.
  - 비용: 레벨이 오를수록 증가 (잠정: 다음 레벨 비용 = 10 × 1.3^(현재 레벨−1), 등급 배율 적용).
  - 기본 성공 확률: 레벨이 오를수록 감소 (잠정: Lv1→2 100% … Lv14→15 30%).
  - **실패 누적 보너스**: 실패할 때마다 그 유물의 다음 강화 확률 +X%p(잠정 +10%p), 성공하면 보너스 초기화 → 계속 시도하면 반드시 성공. 화면에 "현재 확률 45% (+20% 실패 보너스)"처럼 표시.
  - **대성공(운빨 요소, 제안)**: 성공할 때 낮은 확률(잠정 5%)로 +2레벨. 만렙 직전에는 +1.
  - 실패해도 조각은 소모 (단, 확률이 오르므로 장기적으로 손해 없이 만렙 도달).
- **효과**: 레벨에 비례해 커짐. Lv1 값 + 레벨당 증가량.
- **유물 예시** (최종 목록·수치는 Phase 2 시작 시 확정, M2 목표 15~20종):

| 유물 | 효과 (Lv1 → 레벨당) | 해금 조건 (예) |
|---|---|---|
| 붕대 | 초당 체력 재생 0.5 (+0.25 / Lv, Lv15 = 4.0) | 처음으로 패배하기 |
| 숫돌 | 공격력 +2% (+1% / Lv) | 몬스터 누적 처치 100 |
| 가죽 장갑 | 공격 속도 +1% (+0.5% / Lv) | 처음으로 10층 도달 |
| 낡은 방패 | 방어력 +3% (+1.5% / Lv) | 층 보스 첫 처치 |
| 돋보기 | 크리티컬 확률 +0.5% (+0.25% / Lv) | 크리티컬 누적 300회 |
| 행운의 동전 | 메소 획득 +5% (+2% / Lv) | 누적 메소 10,000 |
| 마나 결정 | 스킬석 드롭 확률 +2%p (+1%p / Lv) | 패시브 스킬 하나를 처음으로 만렙 |
| 대장장이 망치 | 장비 강화 확률 +1%p (+0.5%p / Lv) | 장비 처음으로 10강 |
| 네잎클로버 | 직업 카드 등급 행운 +2% (+1% / Lv) | 레전더리 이상 직업 카드 첫 획득 |
| 상인의 저울 | 상인 거래 비용 −5% (−2% / Lv) | 상인 거래 누적 5회 |
| 악마의 계약서 | 악마 거래 대가 −5% (−2% / Lv) | 악마 거래 누적 3회 |
| 천사의 깃털 | 판마다 부활 1회, 체력 20% (+3% / Lv) | 처음으로 30층 도달 |
| 타로 덱 | 직업 카드 선택지 +1장 (레벨당 등급 행운 +0.5%) | 처음으로 4차 전직 |
| 금빛 나침반 | 황금 몬스터 등장 확률 +0.5%p (+0.2%p / Lv) | 황금 몬스터 첫 처치 |

  - '천사의 깃털'·'타로 덱'처럼 **할 수 있는 게 늘어나는 해금형 효과**를 일부 넣어서, 숫자만 오르는 성장이 되지 않게 함.
- **탑의 조각 (재화)**: 판이 끝날 때 지급. 잠정 공식 = 도달 층 × 10 + 보스 처치 수 × 20 + 황금 몬스터 보너스 + 시련방 보너스. 실패·중단한 판도 지급.

### B. 판 정산 화면 (아웃게임)
- 기존 결과 팝업을 정산 화면으로 확장: 도달 층, 처치 수, 최고 한 방 데미지, 이번 판 최고 등급 직업 카드.
- 획득 목록이 하나씩 올라가는 연출: 탑의 조각 / 여신의 깃털 / 새 심볼 / **새로 해금된 유물** / 최고 기록 갱신(강조).
- 로비에 "탑의 조각 N개 — 강화 가능한 유물 M개" 표시.

### C. 운빨 뽕맛 (판 안 + 유물 강화)
- **유물 강화 연출**: 강화 버튼 → 유물이 흔들리며 빛이 모였다가 성공/실패/대성공 판정. 대성공은 화면 전체 금빛 연출. 실패는 "다음 확률 +10%" 표시로 아쉬움을 다음 시도로 연결.
- **직업 카드 뒤집기**: 3장이 뒤집힌 채 나오고, 고등급일수록 카드가 먼저 떨리고 빛이 새어 나온 뒤 뒤집힘. 등급별 효과음.
- **직업 카드 천장**: 이번 판에서 레전더리 이상이 K번(잠정 8번) 선택 동안 안 나오면 다음 선택에 1장 확정. 판마다 초기화.
- **황금 몬스터(잭팟)**: 일반 스테이지에서 낮은 확률(잠정 2%)로 금빛 몬스터 등장 — 처치 시 메소 ×5 + 탑의 조각 보너스, 화면 금빛 연출.
- **테스트 옵션 정리**: 매 선택 미스틱 확정 테스트 옵션을 끄고 실제 확률로 (Phase 1).

### D. 로그라이크 선택 (판 안, 최소 버전)
- **보스 뒤 갈림길**: 층 보스 처치(거래 뒤)마다 다음 층으로 가는 길 2개 중 선택.
  - 보물방: 다음 층 첫 스테이지가 상자 — 메소·스킬석·장비 강화권 중 무작위 보상.
  - 시련방: 다음 층 몬스터 전부 엘리트(강함), 대신 그 층 메소 2배 + 탑의 조각 보너스.
- 고르는 순간 위험과 보상이 갈리게 해서 판마다 다른 흐름을 만든다. 방 종류 확장은 M3.

### Phase 1 — "기반 정리: M1 검증 마무리 + 테스트 옵션 끄기"
> 상세 계획: `OrbisTower-M2-Phase1.md`
- ✅ 1. 테스트 옵션 끄기 (특성 카드 미스틱 확정 해제) — 플래그 false 확인, 실제 선택 등급 샘플(2·1·3 / 2·1·2 / 2·3·1 / 1·2·2)에 강제 미스틱 없음
- 🟡 2. 스킬 테스트 버튼·맵 출시 처리 — 결정: 메이커 플레이에서만 표시 (`Environment:IsMakerPlay()`). 메이커에서 표시 확인  ⚠️ 사용자 테스트 필요: 출시(퍼블리시) 월드에서 버튼이 숨겨지는지
- ✅ 3. 판 진행 핵심 동작 일괄 점검 (전투·층·보상·레벨·패배 초기화·중단하기) — 전투→처치→보상→레벨업→스테이지/층 상승→엘리트→깃털, 중단하기→확인→패배→결과 팝업→다시 도전(1층·Lv1·메소 0) 확인
- 🟡 4. 전투 능력치 동작 확인 (방어력·크리티컬·명중↔회피) — 공식은 코드로 확인(방어: def/(def+100), MISS: 몬스터 회피−명중, 크리 확률·배율 전달)  ⚠️ 사용자 테스트 필요: 실제 수치 체감
- ✅ 5. 패시브 스킬 10종 + 스킬석 강화 + 스킬 탭 확인 — 레벨 해금(Lv1·3·5), 스킬석 강화 성공·실패와 이펙트 확인
- ✅ 6. 공격 모션·피격·사망 연출·데미지 숫자 확인 — 공격 모션·데미지 숫자 화면 확인, 사망 애니메이션 1회 재생 로그 확인
- ✅ 7. 특성 발현·전직·직업 스킬 / 보스 거래 확인 — 시작 5장·레벨업 3택, 100포인트 1차 전직(포인트 초기화·직업 스킬), 보스 거래(천사) 적용 확인

### Phase 2 — "져도 남는다: 유물" (아웃게임 1순위)
