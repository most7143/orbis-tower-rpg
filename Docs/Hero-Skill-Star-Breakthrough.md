# 히어로 별 강화·돌파 옵션 설계

- 작성일: 2026-11-03
- 상태: 기획 초안 / 밸런스 검증 전
- 범위: 히어로 고유 패시브의 공통 판정, 액티브 15종의 별 강화와 돌파 옵션
- 이 문서는 대화에서 합의한 방향을 정리한 별도 설계안이다. 기존 GDD·코드·데이터를 수정하거나 구현 완료를 의미하지 않는다.
- 아래 돌파의 개별 수치는 합의한 ‘별 강화 약 2회 가치’에 맞춰 정리한 제안값이다. 실전 효율은 검증이 필요하다.

## 1. 확정 방향

- 고유 패시브: 콤보 어택. 장착 칸을 사용하지 않는다.
- 액티브: 총 15종 중 5종 장착.
- 기본 해금: 1~5번. 나머지는 표 순서대로 해금.
- 아웃게임: 스킬 해금·영구 강화·장착.
- 인게임: 장착 스킬에 별 강화·돌파를 적용. 판 종료 시 인게임 강화 초기화.
- 전투: 몬스터 1명과 싸우는 1대1 구조. 대상 수 증가는 옵션으로 사용하지 않는다.
- 발동: 쿨타임형·기본 공격 적중 시 확률형·마나형.
- 콤보: 발동을 막는 네 번째 코스트가 아니라 히어로의 강화 자원. 콤보가 부족해도 소모형 스킬은 기본 위력으로 발동한다.
- 빌드: 콤보 소모 / 콤보 유지 / 검술 연계 / 소환검 / 자상·출혈.

### 기본 자원·연계 판정

- 콤보(고유 패시브 콤보 어택): 아웃게임에서 스킬북으로 레벨을 올려야 해금된다(Lv.0 잠김, Lv.1 해금, 최대 Lv.11). 해금 후 콤보를 소비하지 않는 직접 공격(기본 공격·균열 포함)이 적중할 때마다 30% 확률로 1 획득, 최대 12. 콤보당 기본 공격력 +(1 + 0.2×(레벨-1))%. 캐릭터 주위에 콤보 어택 아이콘이 1~6스택까지 하나씩 생기고(배경 시계 방향·아이콘 반시계 방향 회전), 7~12스택은 어드밴스드 콤보 아이콘으로 순서대로 바뀐다(배경 교체, 배경 회전 정지).
- 콤보는 자연 감소하지 않는다. 콤보 소비 스킬로만 줄어든다.
- 콤보 소모 조건: 패닉 3, 코마 2, 업라이징 5, 데스폴트 5. 충분할 때만 소비하고 강화한다.
- 기본 소모 보너스: 패닉 +60%, 코마 +50%, 업라이징·데스폴트 +70%.
- 콤보 보너스는 소비 직전 수치로 계산한다.
- 마나: 최대 100, 전투 시작 30, 초당 5 회복, 기본 공격 적중 시 2 회복을 초안으로 사용한다. 카드 선택·몬스터 교체 중 회복 정지.
- 자상: 기본 6초, 최대 10중첩, 중첩당 초당 공격력 15% 피해. 재부여 시 지속시간 갱신. 기본 인사이징은 3중첩 부여.
- 소환검: 기본 1.5초마다 공격. 검술 발동당 충전 1, 필요 충전 5. 강화 공격은 일반 공격의 1.5배 피해.
- 인레이지: 기본 공격력 +25%, 지속 중 기본 공격의 콤보 획득량 총 2.
- 발할라: 기본 공격력 +30%, 검술 발동에 추가 검격. 추가 검격 간격 최소 1초.
- 에픽 어드벤쳐: 기본 모든 피해 +30%, 마나 자연 회복량 +50%.
- 인스팅트: 지속 중 콤보당 직접 공격 피해 보너스가 +2%에서 +5%로 대체, 콤보 자연 감소 정지. 기본 공격에 균열 동반. 활성 중 재발동·시간 갱신 불가.
- 기본 패닉에는 체력 조건 피해 보너스가 없다. 기존 구안의 체력 30% 이하 보너스는 이번 기본안에서 제외한다.

별 강화는 기본 성능만 높인다. 코스트 감소·확률 증가·타수 증가·자원 수급·연계 변경은 돌파에 둔다.

| ID | 이름 | 선택 1회 효과 |
|---|---|---|
| STAR_POWER | 위력 강화 | 해당 스킬의 모든 피해 +30%. 버프는 기본 화력 증가 효과를 기본값의 30%만큼 추가 강화 |
| STAR_TEMPO | 속도·지속 강화 | 직접 공격형은 해당 스킬 공격 동작 속도 +20%, 소환형은 소환검 공격속도 +20%, 버프형은 지속시간 +25% |
| STAR_CRITICAL | 치명 강화 | 해당 스킬 치명타 확률 +10%p, 치명타 피해 +20%p. 버프형은 지속 중 캐릭터에게 같은 수치 부여 |

### 별 강화 계산

- 같은 옵션의 반복 선택은 합산한다. 위력 3회면 해당 스킬 피해 +90%.
- 버프 위력 강화는 기본값 기준: 인레이지 공격력 +25%에 위력 1회면 +32.5%, 2회면 +40%.
- 버프에 돌파로 추가된 별도의 특수 보너스까지 별 위력으로 재증폭하지 않는다.
- 공격 동작 속도는 스킬 동작 시간을 줄인다. 쿨타임·발동 확률·마나 비용·출혈 틱 간격은 바꾸지 않는다. 동작 속도 +20%면 동작 시간은 기본 시간 / 1.2.
- 소환검 공격속도 +20%면 공격 주기는 기본 주기 / 1.2.
- 속도에 따른 공격 가능 시간 증가의 실제 효율은 전투 동작 처리와 함께 검증한다.
- 치명타 확률은 최대 100%. 비치명 출혈에는 치명 강화가 적용되지 않는다.
- 콤보 어택은 고유 패시브이므로 이 액티브 공통 별 옵션 목록의 대상에서 제외한다. 고유 패시브 별도 성장표는 이번 문서에서 확정하지 않는다.

## 4. 돌파 공통 규칙

1. 스킬마다 후보 5개. 한 판에 같은 스킬에 서로 다른 돌파 2~3개를 붙일 수 있다.
2. 동일 돌파 중복 획득 불가. 스킬당 최대 3개.
3. 돌파 1개의 목표 가치는 별 강화 1회의 약 2배다. 최종 피해를 무조건 2배로 만든다는 의미가 아니다.
4. 기준: 피해 +60%, 공격속도 +40%, 지속시간 +50%, 치명타 확률 +20%p와 치명타 피해 +40%p의 묶음.
5. 특수 효과는 위 기준과 비슷한 실전 가치를 목표로 한다. 조건부 효과는 대략 피해 +70~90%, 마나·쿨타임 감소는 35~40%를 출발점으로 삼는다.
6. 복합 옵션은 각 효과가 아니라 전체 묶음을 기준으로 평가한다.
7. 같은 계열 피해 보너스는 합산한다. 별·돌파의 동일 스킬 피해 증가도 같은 항에 합산한다.
8. 기본 기능을 없애거나 코스트를 제거하는 옵션은 두지 않는다. 소모·유지 빌드의 차이를 남긴다.
9. 획득한 돌파로 자원·버프 상태가 변해도 다음 조건을 만족해야 실제 효과가 발생한다.

### 적용 순서

- 기본 위력·타수·확률·비용 → 별·돌파의 수치 변경 → 공격 조건 평가 → 최종 피해.
- 타수 추가는 타당 기본 계수를 따른다. 피해 보너스가 추가 타수에 다시 별도로 중복 곱해지지 않는다.
- 비용 감소는 기본 비용 기준 합산. 마나 비용은 소수점 올림.
- 기존 콤보 소모 보너스를 바꾸는 옵션은 기본값을 대체한다. 그 외 스킬 피해 증가와는 별도 항이며 동일 소모 보너스는 한 번만 적용한다.
- 체력 조건은 타격 직전 몬스터 체력 비율 기준.
- 버프 재발동은 중첩하지 않고 시간만 갱신한다. 이미 활성인 효과를 별도 개체로 중복 생성하지 않는다.

## 6. 중첩·의존성·무한 연쇄 방지

### 수치 예시

- 별 위력 +30%를 2회, 돌파 피해 +60%를 얻으면 해당 스킬 공통 피해 보너스는 총 +120%, 기본의 2.2배다.
- 패닉의 마나 감소 돌파는 기본 20의 40% 감소로 12가 된다. 후속 비용 감소가 생기면 원래 20을 기준으로 합산한다.
- 인레이지 별 위력 1회와 광전사의 분노: 기본 25 + 별 7.5 + 돌파 15 = 공격력 +47.5%.
- 콤보 인스팅트 별 위력 1회와 한계를 넘은 투지: 기본 콤보당 5 + 별 1.5 + 돌파 3 = 콤보당 +9.5%.
- 슬래시 별 위력 +30%와 잔상 베기: 원본이 기본의 1.3배, 잔상은 그 60%. 합계 2.08배. 잔상에 별 보너스를 다시 곱하지 않는다.
- 인스팅트의 콤보 환급은 소비량을 소수점까지 누적한 뒤 정수 1이 될 때마다 반환한다. 환급된 콤보는 소비로 계산하지 않는다.

### 조건부 등장

- 소환검 관련 돌파는 버닝 소울을 장착했을 때만 등장한다.
- 자상 관련 돌파 중 스스로 자상을 생성하는 옵션은 단독으로 등장 가능하다. 자상을 소비하거나 조건으로만 쓰는 옵션은 자상 생성 수단을 갖췄을 때 등장한다.
- ‘다음 다른 검술’ 또는 ‘직전과 다른 검술’ 옵션은 서로 다른 검술 2종 이상 장착 시 등장한다.
- 서로 다른 검술 3종 조건은 검술 3종 이상 장착 시 등장한다.
- 획득 순서에 따라 유효한 돌파가 없으면 해당 스킬의 돌파 선택을 강제하지 않는다. 실제 카드 추첨 방식은 구현 단계에서 정한다.

### 발동 판정

- 확률형은 기본 공격 적중당 스킬별 1회 판정. 다단히트·추가 공격·소환검·출혈로 다시 확률 판정을 하지 않는다.
- 검술 연계는 스킬 사용 단위로 계산한다. 한 번의 소드 일루전은 타수가 많아도 검술 1회다.
- 동일 기본 공격에서 여러 확률 스킬이 발동하면 처리 순서는 장착 슬롯 순서다.
- 서로 다른 검술 3종 조건은 첫 검술부터 ID를 모으고, 같은 검술 반복은 개수를 늘리지 않는다. 3종 충족 시 발동 후 수집 목록을 비운다.
- 발할라 원본 검격은 충전·연계 지원을 유발할 수 있지만 잔상 검격은 다시 유발하지 않는다.
- 추가 소환검은 별도의 충전·자상 발생 횟수를 만들지 않는다. 충전은 공유하고, 피를 먹는 검의 자상은 원본 검만 부여한다.
- 검의 지휘자가 명령한 강화 공격은 소환검 충전과 별개다. 충전을 소비하거나 새 검술·확률 스킬을 발동시키지 않는다. 쌍영검은 같은 공격 명령에 자신의 60% 위력으로 동참한다.
- 귀환 검기·여진·잔흔·잔상은 원본 공격의 대상·조건·피해를 기준으로 추가 피해를 주며, 새로운 스킬 발동으로 계산하지 않는다.
- 같은 출처의 ‘다음 공격 강화’는 중첩하지 않고 갱신한다. 서로 다른 출처의 피해 증가가 같은 공격에 걸리면 증가율을 합산한다.
- 쿨타임 감소는 남은 시간을 0까지만 줄인다. 이미 실행 중인 스킬을 즉시 중복 실행하지 않는다.
- 버닝 소울 재발동은 검을 중복 소환하지 않고 지속시간 갱신. 쌍영검도 총 2개 유지.
- 마나형의 사용 우선순위와 기본 공격 동작 점유 시간은 모든 스킬의 실제 효율에 영향을 주므로 함께 검증한다.

### 피해·상태 귀속

- 출혈의 기본 틱은 비치명. 파열·소모 추가 피해는 별도의 치명타 가능 직접 공격으로 처리한다.
- 인사이징의 별·돌파 피해 증가는 인사이징이 부여한 자상에만 적용한다. 다른 스킬이 생성한 자상까지 자동 강화하지 않는다.
- 자상은 중첩별 출처와 피해 계수를 보관한다. 소비는 오래된 중첩부터, 지속시간 갱신은 전체 중첩에 적용한다.
- 자상 소비 피해는 소비한 틱 피해를 재사용하지 않고, 소비 스킬에 명시된 계수로 계산한다.
- 콤보당 직접 공격 피해 보너스는 직접 타격·파열에 적용하고 소환검·출혈에는 적용하지 않는다. 발할라 검격과 인스팅트 균열은 직접 추가 공격으로 분류한다.
- 발할라·인스팅트의 별 치명 강화는 캐릭터에게 한 번만 적용한다. 별 강화 수치를 검격·균열에 다시 더하지 않는다.
- 코마의 약점은 몬스터 디버프이며 동일 효과는 중첩하지 않고 시간만 갱신한다.

## 7. 빌드별 5차 포함 예시

| 빌드 | 장착 예시 | 5차 수 | 돌파 방향 |
|---|---|---:|---|
| 콤보 소모 | 슬래시 블러스트 / 패닉 / 인레이지 / 업라이징 / 데스폴트 | 1 | 투지의 원천·과잉 응축·응축된 분출·전력 해방 |
| 콤보 유지 | 브랜디쉬 / 인레이지 / 레이징 블로우 / 버닝 소울 / 인스팅트 | 2 | 완숙한 검술·절제된 격노·완성된 검·한계를 넘은 투지 |
| 검술 연계 | 슬래시 블러스트 / 브랜디쉬 / 오라 블레이드 / 발할라 / 소드 일루전 | 1 | 연계의 시동·교차 검격·검술의 길잡이·검술의 합창 |
| 소환검 | 브랜디쉬 / 인레이지 / 발할라 / 에픽 어드벤쳐 / 버닝 소울 | 1 | 영혼의 격노·영혼의 동행·쌍영검·검술 공명 |
| 자상·출혈 | 인사이징 / 패닉 / 에픽 어드벤쳐 / 버닝 소울 / 소드 일루전 | 2 | 피로 물든 검·흉터 파열·피를 먹는 검·상흔 붕괴 |

위 표는 완성형 장착 예시다. 5차 해금 전에도 각 빌드의 하위 스킬로 플레이할 수 있어야 한다. 후반 5차가 빌드를 강화하지만 초반 플레이를 막지 않는다.

## 8. 검증·후속 결정

- 돌파는 평균적으로 별 2회 가치를 목표로 하지만, 마나 공급·발동 속도·전투 길이·자상 포화·최대 콤보 유지율에 따라 실전 효율이 달라진다. 수치만으로 동등 효율이 검증된 것은 아니다.
- 인레이지·발할라·에픽·인스팅트의 별 위력은 원래 버프량의 30% 추가이고, 지속 중 치명 보너스는 독립된 효과다. 이 둘의 실제 가치가 다른 스킬의 별 옵션과 맞는지 우선 확인한다.
- 마나 감소 돌파는 공급이 충분할 때 최대 약 1.67배 사용 효율을 목표로 한다. 우선순위에 따른 다른 스킬 발동 지연까지 평가한다.
- 코마의 기절 면역 대응과 약점 디버프의 보스 적용 여부를 실제 몬스터 규칙과 확인한다.
- 동일 스킬 돌파 2~3개 조합의 곱효율, 특히 확률 증가 + 추가타 + 자원 수급을 점검한다.
- 별·돌파 획득 레벨과 카드 추첨 방식은 미확정이다. 이전 ‘최대 Lv.6·돌파 2회’ 제안은 이번 ‘스킬당 2~3돌파’ 방향에 맞춰 별도로 개편해야 한다.
- 고유 패시브 콤보 어택의 별도 별·돌파 목록은 이번 확정 범위에 포함하지 않는다.
- 이 문서에는 런타임 테스트 결과가 없다. 구현 시 기존 데이터·스크립트·GDD와의 변경점을 조정하고 Maker에서 검증해야 한다.
