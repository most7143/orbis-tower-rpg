# 각인 개편 기준 (사용자 확정 2026-11-22)

## 사용자 확정
- 성장창 각인 탭 왼쪽 영역 안에 **공격 / 방어 / 특수** 탭을 둔다.
- 각 탭 안에 여러 성장 루트가 있다. 예: 공격 탭 — 공격 집중 루트, 상태이상 강화 루트, 쿨타임·회복(가속) 루트.
- 한 루트를 찍을수록 다음 단계가 강화·해금되는 느낌.
- 포인트: **클리어한 최고 층 수** 기준(사용자 확정, 지금처럼). 기존에 찍은 각인 포인트는 돌려주고 새로 찍게 한다.
- 초기화: **항상 무료**.
- 루트 선택: **한 탭에서 여러 루트를 자유롭게 섞어 찍기**.

## 구조 (메인 세션 초안, 구현 중 조정 가능)
- 탭 3개 × 루트 3개 × 5단.
  - 1~4단: 칸 2개씩, 칸마다 최대 3레벨.
  - 5단: 핵심 칸 1개(1레벨, 강력).
- 해금: 그 루트에 쓴 포인트 기준 — 2단 3점, 3단 6점, 4단 9점, 5단 12점(4단까지 칸 하나 이상 찍음 + 포인트 조건).
- 루트 보너스: 루트에 쓴 포인트 5·10·15에서 그 루트 특성 보너스(예: 파괴 5점 공격력 +3%).
- 오른쪽 영역: 선택한 칸 설명·현재/다음 값·레벨업 버튼, 탭·루트 투자 현황, 무료 초기화 버튼(탭별/전체).

## 루트 (초안)
| 탭 | 루트 1 | 루트 2 | 루트 3 |
|---|---|---|---|
| 공격 | 파괴: 공격력·치명타·치명타 피해·처형 / 핵심: 일정 확률 최종 피해 2배 | 상태이상: 화상·출혈·중독 피해·지속·부여 확률 / 핵심: 상태이상 걸린 적이 받는 피해 증가 | 가속: 쿨타임 감소·공격 속도·궁극기 충전 / 핵심: 궁극기 사용 후 스킬 쿨타임 초기화 |
| 방어 | 강인: 체력·방어·받는 피해 감소 / 핵심: 판마다 1회 버팀 | 회복: 처치 회복·흡혈·클리어 회복 / 핵심: 피격 시 보호막 | 반격: 회피·가시·철벽 / 핵심: 회피 시 반격 |
| 특수 | 재화: 판 안 메소·금색 메소·스킬석 | 돌파: 돌파 다시 고르기·추가 선택 확률·마법의 서 | 탐험: 상점 할인·미스터리 보상·여신 |

- "마나"는 게임에 없으므로 쿨타임·궁극기 충전이 그 역할.
- 상태이상(화상·출혈·중독)은 기존 판 안 상태(자상/흉터·화상·톡신 등) 처리 방식을 조사해 연결. 없으면 공용 상태이상 처리 추가.

## 저장·구현 원칙
- 기존 각인 데이터는 `PlayerEngrave`(유물 세션 작업 중 파일)에 있으므로, 새 각인은 **새 컴포넌트·새 저장 키**(예: `Character/PlayerTalent.mlua`, `OrbisTalentV1`)로 만든다. 계정 레벨·포인트 수는 PlayerEngrave에서 읽기만.
- 판 반영은 TowerRunManager에서 옛 각인 대신 새 데이터를 읽는다(옛 경로 호출은 끊기).
- 화면은 기존 성장창 각인 탭(ui/EngraveUI + EngraveUILogic)을 새 구조로 다시 만든다. 창 배치·버튼 상태 이미지·툴팁 규칙 준수.

## 구현 단위 (2026-11-22 확정)

### 공통 규칙 (E-A에서 확정)
- 탭 3(공격 Atk / 방어 Def / 특수 Util) × 루트 3 × 5단. 1~4단은 칸 2개(칸마다 최대 3레벨), 5단은 핵심 칸 1개(1레벨). 루트당 최대 25점, 전체 225점.
- 해금: 그 루트에서 **그 단보다 아래 단에 쓴 포인트** 2단 3 · 3단 6 · 4단 9 · 5단 12. 5단은 추가로 4단 칸 하나 이상에 포인트가 있어야 한다. (근거: 칸 하나를 만렙 3까지 찍으면 바로 다음 단이 열려 "찍을수록 열리는" 흐름, 4단까지 최소 12점이면 핵심 칸이 루트 절반 투자 보상이 됨)
- 루트 보너스: 그 루트 포인트 합 5 · 10 · 15에서 자동 적용 (TalentRouteTable).
- 총 포인트: **클리어한 최고 층 수 기준(사용자 확정)** — 기존 각인 규칙과 같이 PlayerEngrave.ClearedFloor를 읽기만 한다. 계산은 `PlayerTalent:TotalPoints()` 한 곳에만 있다. 쓴 포인트가 총 포인트보다 많아도 판에는 그대로 반영하고 레벨업만 막는다. 옛 각인(OrbisEngrave)에 찍은 포인트는 새 구조에서 다시 찍는다(옛 데이터는 읽지도 지우지도 않음).
- 초기화: 항상 무료, 탭별 또는 전체. 해금은 계정 Lv3(UnlockTable Engrave).
- 저장: `OrbisTalentV1` = `v=1;n=Id:레벨,...` (표에 없는 칸·모르는 키 원문 보존). 칸을 찍으면 2초 모아 저장, 초기화·창 닫기는 바로 저장, 실패 시 5초 뒤 재시도.

### E-A 데이터·서버·판 반영
- `Data/TalentTable`, `Data/TalentRouteTable`, `Character/PlayerTalent.mlua`(DefaultPlayer 부착), TowerRunManager가 옛 `PlayerEngrave.BuildValues` 대신 `PlayerTalent:TalentRunData()`를 읽음, 핵심 칸 연결.
- 확인: 칸 찍기 성공·해금 거부(err_tier/err_core)·포인트 부족 거부, 무료 초기화(탭·전체), 남은 포인트, 판 시작 효과 로그(`talent run data`).

### E-B 화면
- 성장창 각인 탭(ui/EngraveUI + EngraveUILogic)을 탭 3 · 루트 3열 · 5단 트리로 다시 만든다. 오른쪽: 선택 칸 설명·현재/다음 값·레벨업, 루트 투자·보너스 현황, 무료 초기화(탭/전체).
- 확인: 칸 상태(잠김·열림·만렙) 표시, 레벨업 버튼 비활성 조건, 초기화 후 갱신, 버튼 상태 이미지·툴팁 규칙.

### E-C 회귀
- 옛 각인 경로가 판에 더해지지 않는지(BuildValues 호출 없음), 유물·은총·펫·장신구 효과가 그대로인지, 핵심 칸 몇 개(섬멸·수호막·해방) 발동 로그 1회씩.

## 중지 후 재개 결정 (2026-11-22, 메인 세션)
- **섬멸**(10% 확률 최종 피해 2배): 피해 숫자를 띄우기 **전에** 판정해 화면에 뜨는 숫자도 2배가 되게 한다.
  - 구현: `TowerRunManager:FinalDouble(dmg)`가 판정하고, 숫자를 띄운 피해는 `ApplyRolledDamage(dmg)`로 다시 판정하지 않고 적용한다.
  - 기본 타격(엔진 피격)은 `TowerPlayer:CalcDamage`에서 판정 → `TowerMonster` 피격 처리가 `ApplyRolledDamage`로 적용. 직업 스킬 숫자(HeroCombat·BishopCombat·JobCombat), 공용 화상 틱, 스킬 피해, 줄 선 몬스터 범위 피해(`ApplySplashDamage`)도 숫자 표시 전에 판정.
  - 숫자 없이 들어오는 피해(가시 반사·폭발·반격 등)는 기존대로 `ApplyMonsterDamage` 안에서 판정. 처형(남은 체력 즉사)은 판정하지 않음.
- **최후의 저항**: 기존 규칙대로 메인 캐릭터만 (변경 없음).
- **칸 설명 툴팁**: 보너스 칸에만 (변경 없음).
