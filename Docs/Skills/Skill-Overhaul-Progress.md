# 스킬 개편 진행 기록 (원본 차수 기준, B안 9칸)

- 작성일: 2026-11-24 · 기준: [Skill-Overhaul-Spec.md](Skill-Overhaul-Spec.md), [skill_overhaul_data.json](skill_overhaul_data.json)
- 상태: 데이터·코드·UI 구현 완료, 메이커 빌드 오류 0, 짧은 기능 확인 1회. 커밋 안 함.

## 1. 확정 사항 (메인 담당 결정)

- 차수 규칙: 1차 = 1차 스킬, 2·3차 = 각 차수 스킬(비누적), 4차 = 4차 + 하이퍼, 5차 = 4차 칸 유지 + 5차 스킬 4개(5차 칸 3 + 궁극기), 각성 = 6차 VI 스킬.
- 칸 구조 B안 9칸: 고유 패시브 · 주력기 · 보조기 · 기술 · 하이퍼 · 5차 칸1~3 · 궁극기 (칸 키 `Passive, Main, Sub, Tech, Hyper, V1, V2, V3, Ult`).
- 각성 1~5단계: 주력기 → 보조기 → 기술 → 하이퍼 → 궁극기 순서로 VI(6차) 스킬로 교체. VI 없는 칸 대체안 확정: 보우마스터 보조기 = 엑스트라 퀴버 카트리지, 바이퍼 하이퍼 = 헤이메이커.
- 속성: None/Fire/Ice/Lightning/Poison/Holy/Dark. 인사이징(H06) `불` → `None`, 소드 일루전(H14) `출혈` → `None`, 소드 오브 버닝 소울(H12) = `Fire`.
- 5차 칸 테두리: 주력기 테두리(등급 1)를 그대로 사용 (새 그림 업로드 없음).

## 2. 구현 방식 (새 내부 Id + 동작 기준 Id)

- **같은 이름 스킬은 기존 Id 유지** (예: H08 레이징 블로우, N04 쉐도우 파트너). 이름·아이콘·설명·속성만 원본 기준으로 바꿈.
- **새 스킬은 새 Id**(H20~, B20~, N20~, A20~, V20~)이고, `JobSkillTable.Base` 열에 **동작 기준 Id**(같은 직업의 기존 스킬)를 적었다.
  - 전투 컴포넌트(`HeroCombat`·`BishopCombat`·`JobCombat`)의 새 메서드 `Alias()`가 판 시작 때 새 스킬의 이름·수치·발동 방식을 기준 스킬에 입히고, 기준 Id로 장착한다. 기준 스킬의 특수 동작·돌파(`SkillBreakTable`)·연출(`SkillActionTable`)이 그대로 따라오므로 자동 전투 분기(N04·A12·V10 등)가 깨지지 않는다.
  - 한 판에 같은 기준 Id가 두 번 장착되지 않게 차수별로 겹치지 않는 기준을 골랐다(아래 표).
  - 기준 스킬과 효과가 다른 새 스킬은 `JobCombat.SpecOverride()`로 효과만 바꿈: 윈드 탈리스만(N21) 넉백, 바람의 시(A20) 기절 제거, 윈드 오브 프레이(A24·A28) 둔화, 럭키 다이스(V22)·라이트닝 폼(V27) 버프(몸집 커짐 제거).
  - 판 매니저 `RegisterSkillAlias()`가 판 스킬 정보(`skillById[기준]`)에 새 이름·속성·공격 타입을 입힌다 → 타격 속성(`HitProfile`)·돌파 카드·마법의 서가 새 스킬 기준. `@Sync SkillAlias`("H02=H21,…")로 클라이언트(타로 카드, HUD 툴팁 돌파 목록)도 새 이름·아이콘을 쓴다. 판 시작 때 `ResetSkillAlias()`로 되돌림.
  - HUD `SlotInfo`는 새 스킬 Id를 보낸다(`DataId()`), HUD 아이콘·툴팁은 새 스킬 행을 읽는다.
- **저장 호환**: 캐릭터 저장(`OrbisRosterV1` CharData)에는 스킬 Id가 없다(차수·각성 레벨만). 칸 스킬은 매번 `CharSlotTable`에서 계산하므로 옛 저장도 새 구조로 바로 열린다. 옛 스킬 행(H03 패닉, N02 드레인 등)은 동작 기준·옛 장착(`PlayerEngrave` 예전 경로) 호환용으로 **표에 남겨 두었다** (화면 칸에는 안 나옴).
- **각성 단계**: 저장된 `awkLv`(지금까지 올리는 기능 없음)를 단계 0~5로 본다(`PlayerRoster.AwakenStage`). 5차 캐릭터만 `SlotsForAwk()`가 단계 이하 칸을 `CharSlotTable.Awk` 스킬로 바꾼다. 캐릭터 화면은 별도 탭 없이 5차 탭에서 각성 스킬로 보이고 툴팁에 "각성 n단계 → ○○ 강화"가 나온다.

## 4. 수치 출처 (`#ValueSource` 열)

- `원본없음-기존값`: 같은 스킬이 이미 게임에 있어 그 값 그대로 (48개).
- `원본없음-차수기준(Hxx 값)`: 새 스킬 — 같은 칸·같은 차수에 있던 기존 스킬(= 동작 기준 Id)의 계수·타수·쿨·마나를 그대로 씀.
- `원본없음-각성기준(Hxx ×1.3)`: VI(6차) — 4차 기준 스킬 계수 ×1.3 (임시).
- `원본없음-차수기준(하이퍼 공격 평균)`: 윈드 오브 프레이 100%×5·쿨 30, VI 130%×5, 헤이메이커 230%×4·쿨 30.
- 원본 XML(`Skill/<직업>.img`)이 생기면 이 열로 찾아 바꾸면 된다.
