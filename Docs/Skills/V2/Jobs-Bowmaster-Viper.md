### 0-2. 연출 시간 표기

- **t=0 = 캐릭터 동작(action) 시작.** 모든 ms는 t=0 기준.
- **판정 시점** 근거: 메이플 몸 동작 데이터에서 **음수 delay 프레임 합 = 공격 판정 시점**이다. 예) 애로우 블로우 `arrowBlow` = [-120, -150, 120…] → 270ms, 같은 스킬의 `shootobj/info startDelay=270`과 일치해 규칙을 확인했다. 음수 프레임이 없는 동작은 "첫 프레임 끝"을 추정값으로 쓰고 **(추정)** 이라 적는다.
- `hitAfter=-N`, `delayShowDamage=N` 가 있는 원본: **타격 이펙트를 피해 숫자보다 N ms 먼저** 재생한다(수룡·충격파 계열). 이 경우 "타격 이펙트 시작 → N ms 뒤 숫자"로 적는다.
- `fix=1` = 맵에 고정(캐릭터를 따라가지 않음), `z<0` = 캐릭터 뒤, `repeat`/`repeatIdx` = 반복 재생(반복 시작 프레임), `scale=200` = 원본이 2배로 그려 재생하는 이펙트(MSW에서도 스케일 2 필요).
- 프레임 수는 XML 기준. 그림 파일 수가 적은 노드(예: 애로우 레인 `tile/0` XML 12f)는 일부 프레임이 다른 프레임을 참조하는 것이므로 **XML delay 목록 그대로 재생**하고 빠진 번호는 참조 프레임을 쓴다.
- 첫 프레임이 긴 빈 그림(210~540ms)인 노드(씨 서펜트 버스트·서펜트 어썰트·윈드 오브 프레이 `effect0` 등)는 **"앞 대기 시간"** 이다. 업로드 시 첫 프레임을 지우면 타이밍이 당겨지므로, 지우면 그만큼 재생 시작을 늦춘다.

# 보우마스터 (아처 → 헌터 → 레인저 → 보우마스터 → 보우마스터 5차)

## 1. 콘셉트와 파티 역할

**"후열의 화살비 — 설치·소환·추적 화살로 화면 전체를 쓸고, 파티 치명타를 끌어올리는 원거리 다수 처리 딜러."**

- 역할: 다수 처리(설치 노포·화살비 영역) + 파티 **치명 확률·치명 피해** 지원(샤프 아이즈) + 근접 아군 보호용 **둔화**(윈드 오브 프레이)·**기절**(피닉스).
- 다른 직업과 맞물림
  - 히어로(아군 공격력 버프 + 콤보): 히어로의 공격력 버프와 샤프 아이즈 치명 버프는 서로 다른 곱셈 축이라 겹치지 않고 곱으로 커진다. 둔화된 적은 히어로가 붙어 있는 시간이 길어져 콤보가 쉽게 쌓인다.
  - 비숍(보호막·피해 증가·회복): 비숍이 버티는 동안 설치물이 쉬지 않고 쏜다. 흡혈 화살이 비숍 회복을 보조(소량).
  - 나이트로드(표식): 보우마스터는 타수가 매우 많아(설치·잔영) 표식 터뜨리기·유지 담당으로 좋다.
  - 바이퍼(전열 돌진·기절·주사위): 바이퍼가 밀치고 모은 적 무리에 애로우 레인 영역이 정확히 떨어진다. 주사위 4(치명) + 샤프 아이즈가 겹치면 치명 확률이 크게 오른다.
- 히어로·비숍과 겹치지 않는 점: 공격력 버프·보호막·회복 없음. 지원은 **치명** 한 축과 **군중 제어(둔화·기절)** 뿐.

- 원본 고유 메커니즘 반영: 최신 원본에는 예전 "에너지 차지·트랜스폼"이 없다. 대신 **씨 서펜트(격투 스킬이 수룡 연계를 깨움) → 서펜트 스톤(수룡 발동마다 1개, 5개 = 어썰트 상태)** 이 바이퍼의 충전 시스템이다. 기존 패시브 이름 "에너지"를 "수룡의 힘(서펜트 스톤)"으로 바꿔 쓴다. 변신은 5차 **라이트닝 폼**.
- 다른 직업과 맞물림
  - 히어로: 둘 다 근접이지만 히어로는 단일 강타·콤보, 바이퍼는 **밀치기·기절로 적을 묶는** 쪽. 기절한 적에게 히어로 강타가 확실히 들어간다.
  - 비숍: 바이퍼가 맨 앞에서 맞는 피해를 비숍 보호막이 받쳐 준다. 주사위 2(방어)·3(회복 대신 체력)과 겹치지 않게 주사위에서 회복은 뺐다.
  - 나이트로드: 기절·밀치기로 모인 적에게 표식 확산.
  - 보우마스터: 밀어 모은 적 무리 위에 애로우 레인. 주사위 4(치명)와 샤프 아이즈가 겹침.
- 히어로·비숍과 겹치지 않는 점: 고정 공격력 버프 없음(주사위는 **무작위·로그라이크 운 요소**), 보호막·회복 없음.

## 6. 결정이 필요한 점

1. **바이퍼 하이퍼**: 원본 하이퍼 액티브인 스티뮬레이트(버프) 대신 **전함 노틸러스**(원본 4차 포격)를 하이퍼로 쓰는 안. 스티뮬레이트 효과는 노틸러스 후 버프로 흡수. 원본 고증을 더 원하면 하이퍼 = 스티뮬레이트, 노틸러스 = 액티브3 4차로 바꿀 수 있다.
2. **앞당긴 스킬 3개**: 보우마스터 애로우 플래터(3차→2차), 샤프 아이즈(4차→3차), 바이퍼 스크류 펀치(3차→2차). 2차 원본 스킬(리트리트 샷 등)이 자동 전투에 맞지 않아서다.
3. **돌진 스킬 복귀 방식**: 돌진 후 300ms 원위치 복귀(제안) / 아예 제자리에서 이펙트만 앞으로 보내기 중 선택.
4. **atom(그림 없는 발사체) 대체 리소스**: 위 표의 대체안으로 갈지, MSW 리소스 검색(msw-search)으로 비슷한 화염 화살·수룡 그림을 따로 찾을지.
5. **기존 기준 문서와 차이**: `00-Master-Spec.md` §3 진화표(애로우 봄·애로우 일루전·트랜스폼·에너지 버스트·데몰리션 등)는 **최신 원본에 없는 옛 스킬**이다. 이 문서는 최신 원본 기준으로 바꿨다. 기준 문서 표를 이 문서로 갱신할지.
6. **넵투누스 궁극기 = 6차 스킬 사용**: 5차 궁극기 자리에 6차 원본을 쓰는 것(기존 기준 문서와 같음). 순수 5차로 하려면 바이퍼 궁극기 후보는 하울링 피스트(그러면 액티브3 5차를 서펜트 스크류로).
