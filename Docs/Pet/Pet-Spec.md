# 펫 시스템 기준 (사용자 확정 2026-11-22)

## 사용자 확정
- 성장창 가장 안쪽 탭(예전 스킬 탭 자리).
- 판 안 전투에서 장착 펫이 캐릭터 뒤를 따라온다(직접 공격 없음, 효과만).
- 등급 5개: 레어 5 · 에픽 5 · 유니크 5 · 레전더리 5 · 초월 3.
- 레전더리부터 조금 좋은 효과, 초월은 게임의 핵심 버프. 참고: 운빨존많겜 펫(뽑기 레벨·등급별 확률·공격력% + 특수 효과).
- 얻는 법: 뽑기. 뽑기 레벨 1~10, 뽑을 때마다 경험치가 쌓여 레벨이 오르고 높은 등급 확률이 오른다. 8레벨부터 초월이 매우 낮은 확률.
- 1회·10회 뽑기.
- 재화: **전용 펫 뽑기권**(아이콘 `a2b8b33a7a834a729bc8fcaa6fd2d7e6`), **다이아로 구매 가능**.
- 장착: **슬롯 해금식 1→3칸**.
- **보유 효과 있음**: 보유한 모든 펫의 공격력%는 장착과 관계없이 합산, 특수 효과는 장착 펫만.

## 메인 세션 초안 (수치는 구현 중 조정 가능)
- 뽑기 레벨 확률(%) — 레어/에픽/유니크/레전더리/초월, 다음 레벨까지 뽑기 횟수:
  - Lv1 70/27/3/-/- (10) · Lv2 62/32/6/-/- (20) · Lv3 55/35/9/1/- (40) · Lv4 50/36/12/2/- (80) · Lv5 45/37/14.5/3.5/- (150)
  - Lv6 41/37/17/5/- (250) · Lv7 37/37/19/7/- (400) · Lv8 34/36/21/8.95/0.05 (600) · Lv9 31/35/23/10.9/0.1 (900) · Lv10 28/34/25/12.8/0.2 (최대)
- 뽑기권 가격: 1장 50 다이아, 10장 450 다이아. 첫 지급 10장. 획득: 층 첫 클리어 10층마다 3장, 별 구간 마지막 상자 5장(소급).
- 중복 획득 = 그 펫 레벨 +1 (최대 10). 레벨에 따라 공격력%·특수 효과 수치 상승.
- 공격력%(1레벨~10레벨): 레어 1~5, 에픽 2~8, 유니크 3~12, 레전더리 5~18, 초월 10~30.
- 특수 효과(등급 방향): 레어 체력·방어·회피·치명타 확률 소폭 / 에픽 주력기·궁극기 피해·궁극기 충전 / 유니크 보스·정예 피해·쿨감·흡혈 / 레전더리 판 시작 돌파 1회·스킬석 획득 증가·스테이지 클리어 회복 증가·상점 할인 등 / 초월: 쁘띠 초롱 돌파 선택지 +1, 쁘띠 데스 판마다 1회 부활, 쁘띠 포니 궁극기 충전 2배.
- 슬롯 해금: 펫 총레벨(보유 펫 레벨 합) 30 → 2칸, 60 → 3칸.
- 판 안: 장착 펫이 파티 뒤에 줄지어 따라 걷는다(stand/move 클립).
- 10회 뽑기에 등급 보장 없음(사용자 확정): 1회 뽑기 10번과 같음. 매번 현재 뽑기 레벨 확률로 뽑고, 뽑을 때마다 경험치가 쌓여 도중에 레벨이 오르면 다음 뽑기부터 새 확률.

## 구현 결정 (P-A, 2026-11-22)
- 데이터 표: `RootDesk/MyDesk/Data/PetTable` (23종: Id P01~P23, 등급, 이름, 묶음 id, 아이콘·stand0·move 클립 RUID, 공격력% 1·10레벨, 특수 효과 키·1·10레벨 값, 설명), `PetGachaTable` (레벨별 등급 확률·다음 레벨 필요 횟수), `PetConfig` (가격·첫 지급·보상·해금·최대 레벨·최대 레벨 중복 환급).
- 레벨별 수치 = 1레벨 값과 10레벨 값 사이 직선 보간(소수 둘째 자리 반올림). 정수형 효과(돌파 횟수 등)는 P-C에서 내림.
- 뽑기 경험치: 레벨마다 0부터 쌓이고 필요 횟수에 닿으면 레벨업(남는 경험치 이월). 10레벨까지 총 2,650회.
- 최대 레벨(10) 펫이 또 나오면 **뽑기권 1장 환급**(PetConfig MaxDupRefund).
- 보상 소급: 층 첫 클리어 10층마다 3장, 별 구간 마지막 상자 5장. 처음 불러올 때 이미 깬 층·구간도 소급 지급.
- 장착: 해금 칸에만, 보유 펫만, 같은 펫은 한 칸만(다른 칸에서 옮김). 총레벨이 내려가 칸이 잠기는 일은 없지만 불러올 때 잠긴 칸은 비운다.

## 구현 단위
### P-A 데이터·서버
- 데이터 표 3종 + `Character/PlayerPet.mlua`(DefaultPlayer 부착, 저장 키 `OrbisPetV1`).
- 확인: 첫 지급 10장, 10회 뽑기(결과·경험치·레벨업), 다이아로 뽑기권 구매, 장착 1칸·해금 수, 확률 모의 로그, 저장 복원.
### P-B 성장창 펫 탭 UI
- 성장창 가장 안쪽 탭(예전 스킬 탭 자리): 보유·미보유 펫 칸, 펫 상세(공격력%·특수 효과), 장착 칸 1~3(잠금 표시), 뽑기 레벨·경험치 막대, 1회·10회 뽑기, 뽑기권 구매, 결과 표시, 결과 코드 한국어 문구.
- 확인: 탭 열기, 뽑기 버튼 → 결과 표시, 장착·해제 반영, 잠긴 칸·뽑기권 부족 시 버튼 비활성.
### P-C 판 안 따라오기·효과
- 판 시작 시 `PetRunData()`로 공격력% 합 적용, 장착 펫 특수 효과 키를 전투·판 운영에 연결, 장착 펫이 캐릭터 뒤를 stand/move 클립으로 따라 걷기.
- 확인: 판 시작 로그로 공격력%·효과 반영, 펫 엔티티 생성·따라오기, 초월 효과(선택지 +1·부활·충전 2배) 동작 1회씩.
### P-D 회귀
- 로비·성장창 다른 탭·캐릭터 뽑기·장비·유물 동작, 저장 키 충돌 없음, 판 1회 정상 종료.

## P-A 후 메인 세션 결정
1. 최대 레벨 펫 중복 시 뽑기권 1장 환급 유지.
2. 쁘띠 초롱(선택지 +1)·쁘띠 포니(충전 2배)는 효과 고정, 레벨은 공격력%만 올림.
