# 층 안 갈림길(포탈) 스테이지 설계

> 상태: 설계 초안 (2026-11-21). 구현 전.
> 유물 시스템(심볼 대체)은 이 작업 뒤로 미룬다.

## 1. 용어

| 용어 | 뜻 | 고르는 곳 |
|---|---|---|
| 층 | 한 판. 로비에서 골라 들어간다 (예: 1층 메이플 아일랜드) | 로비 |
| 스테이지 | 층 안의 한 칸. 끝나면 포탈로 다음 스테이지를 고른다 | 층 안 포탈 |
| 웨이브 | 전투 스테이지 안에서 몰려오는 몬스터 한 무리 | 자동 |

- 지금 코드의 `Stage`·`StagesPerFloor`는 실제로는 웨이브 단위다. 구현할 때 이름을 웨이브로 바로잡는다.

## 2. 확정 사항

1. 한 층의 전투 스테이지는 **보스 포함 10개로 고정**한다. 전투10이 보스다.
2. 비전투 스테이지는 전투 사이에 **끼어드는 추가 칸**이다. 들러도 전투 횟수는 그대로다.
3. 스테이지가 끝나면 맵에 **선택지 포탈**이 놓인다. 한 번에 **최대 3개**, 항상 3개는 아니다 (1~3개).
4. 보스 처치 뒤에 나오던 천사·악마 거래는 **비전투 스테이지 하나(거래)**로 바꾼다. 보스를 잡으면 층 클리어로 끝난다.
5. **휴식 스테이지는 뺀다.** 회복·부활은 물음표 사건이 맡는다.
6. **정비소(구 상점)는 전투 3·6·9번 뒤에 반드시 나온다.** 그 밖의 때에는 나오지 않는다.
7. 정비소에서는 **장신구(반지·펜던트·귀고리)**를 사서 구성원에게 끼운다. 장착·교체는 정비소에서만 할 수 있다 (8장).
8. **판 안의 '메소로 장비 강화'는 없앤다.** 판 안의 메소는 정비소 장신구에만 쓴다. 장비는 나중에 아웃게임으로 옮긴다.
9. **정예 전투 보상 = 메소 + 아웃게임 재화(여신의 깃털·주문서·책).** 돌파는 주지 않는다.
10. **돌파는 전투 스테이지가 끝날 때마다 고른다** (전투 1~9 뒤, 보스 뒤에는 없음 → 한 판 9번).
    - 카드는 **직업당 1장씩, 3장**을 보여 준다 (구성원마다 자기 직업 돌파 1장).
    - 어떤 구성원이 더 고를 돌파가 없으면 그 칸은 다른 구성원의 돌파 카드로 채운다.
11. **전투 후 자동 별 강화는 뺀다.** 레벨업은 남긴다 (능력치만 오름).
12. **장신구 효과는 낀 구성원에게만** 적용한다 (처치 메소만 파티 전체).
13. **스킬 별 등급은 판을 시작할 때의 아웃게임 등급으로 고정**한다. 판 안 성장은 돌파·장신구·레벨이 맡는다.
14. **전투 보상**: 일반 = 메소 + 아웃게임 재화 조금, 정예 = 메소 + 재화 많이, 보스 = 정예보다 많은 재화 + 층 클리어 정산.
15. **장신구 가격·다시 뽑기 비용은 8-5 초안대로** 구현하고 플레이하며 맞춘다.
16. **물음표 사건 목록은 나중에 정한다.** 처음 구현에서는 사건 2~3개로 가볍게 넣는다.

## 4. 포탈 등장 규칙

### 4-1. 굴리는 순서 (확정: 일반 포탈은 마지막에 남은 자리를 채움)

1. 확정 포탈을 먼저 놓는다 (전투 3·6·9번 뒤의 정비소).
2. 특별 포탈(정예·물음표·거래)을 **각각 따로** 확률로 굴린다.
3. 합쳐서 3개를 넘으면 확률로 뜬 것 중에서 무작위로 빼서 3개로 맞춘다 (확정 포탈은 빼지 않는다).
4. 남은 자리가 있으면 **일반 전투 포탈을 마지막(맨 오른쪽) 자리에** 놓는다. 3개가 다 찼으면 일반 포탈은 뜨지 않는다.

### 4-2. 특별 포탈 확률 (초안, 유지)

| 포탈 | 확률 | 분류 | 비고 |
|---|---|---|---|
| 정예 전투 | 50% | 전투 | 전투 횟수 +1 |
| 물음표 | 25% | 비전투 | |
| 거래 | 10% | 비전투 | 한 층에 1번만 |
| 정비소 | 확정 | 비전투 | 전투 3·6·9번 뒤에만 |

포탈 개수 분포(계산값):

| 상황 | 일반만 1개 | 2개 | 3개 |
|---|---|---|---|
| 평소 | 33.8% | 48.8% (특별1+일반) | 17.4% (특별2+일반 16.2%, 특별3 1.2%) |
| 전투 3·6번 뒤 | — | 33.8% (정비소+일반) | 66.2% (정비소+특별1+일반 48.8%, 정비소+특별2 17.4%) |
| 전투 9번 뒤 | — | 67.5% (정비소+보스) | 32.5% (정비소+특별1+보스) |

### 4-3. 예외 규칙

1. **비전투 다음은 전투만 (확정)**: 지금 스테이지가 비전투(정비소·물음표·거래)였다면, 다음 포탈은 전투 스테이지 중에서만 나온다. 정예만 굴리고 남은 자리는 일반으로 채운다 → 일반 1개 또는 정예+일반 2개.
2. **전투 9번 뒤의 전투는 보스만 (확정)**: 전투를 9번 깬 뒤에는 전투 포탈이 보스로만 나온다. 정예는 굴리지 않고, 일반 자리를 보스가 대신한다.
   - 보스 포탈이 늘 보이도록 비전투는 최대 2개까지만 남긴다 (정비소 확정 + 물음표·거래 중 최대 1개).
   - 비전투 스테이지에 들어갔다 나오면 규칙 1에 따라 다음 포탈은 보스 1개뿐이다.
3. **정예를 고른 경우도 전투 횟수에 포함**되므로, 정비소가 확정되는 '전투 3·6·9번 뒤'는 일반·정예 구분 없이 센다.
4. **첫 스테이지**: 층 시작은 항상 일반 전투로 들어간다 (포탈 없음).

## 5. 비전투 스테이지 내용

공통 흐름:
1. 포탈로 들어가면 페이드인 뒤 맵 가운데에 그 스테이지의 NPC·물건이 서 있다.
2. 화면이 자동으로 열려 고르게 한다.
3. 다 고르거나 '떠나기'를 누르면 맵에 전투 포탈이 나타난다 (4-3 규칙 1).
4. 탭 몇 번으로 끝나서 20~30초 안에 넘어간다.

### 5-1. 정비소

- 고민거리: 어떤 장신구를 누구에게 끼울지, 다시 뽑기에 메소를 더 쓸지.
- 내용은 8장(장신구)에 정리한다. 소모품(회복·부활)은 팔지 않는다. 회복·부활은 물음표 사건이 맡는다.

### 5-2. 거래

- 고민거리: 안전하게 받을지, 대가를 치르고 크게 받을지.
- 지금의 천사·악마 거래 화면(`DealUI`)과 효과(`DealTable`)를 그대로 쓴다. '아무것도 고르지 않기'도 유지.
- 고르면 천사·악마 이펙트가 구성원 가운데에 나온다 (구현됨).
- 한 층에 1번만 나온다.

### 5-3. 물음표

- 고민거리: 운에 걸어 볼지.
- 사건 하나를 무작위로 뽑아 카드 한 장으로 보여 준다. 대부분 선택지 2개(받기/지나치기).
- 비율: 좋은 사건 60%, 위험과 보상이 함께 있는 사건 30%, 나쁜 사건 10%.

| 사건 | 분류 | 내용 | 선택 |
|---|---|---|---|
| 보물 상자 | 좋음 | 메소 또는 아웃게임 재화 | 열기 |
| 수상한 샘물 | 좋음 | 구성원 전원 체력 60% 회복 | 마시기 |
| 잊힌 무덤 | 좋음 | 쓰러진 구성원 전원 부활 (없으면 메소) | 확정 |
| 떠돌이 장인 | 좋음 | 장신구 1개를 반값에 사서 바로 끼운다 | 산다 / 지나친다 |
| 도박꾼 | 위험·보상 | 가진 메소의 절반을 걸고, 50% 확률로 2배 | 건다 / 지나친다 |
| 저주받은 제단 | 위험·보상 | 최대 체력 −10%를 대가로 돌파 1번 | 받는다 / 지나친다 |
| 함정 | 나쁨 | 구성원 전원 체력 −15%, 대신 메소 획득 | 확정 |

## 6. 스테이지 전환 연출

1. 스테이지가 끝나면 맵 오른쪽에 포탈들이 나타난다. 포탈 위에 이름(전투·정예·보스·정비소·물음표·거래)을 표시한다.
2. 포탈을 클릭하면 구성원 3명이 그 포탈까지 걸어간다 (걷기 동작 재생).
3. 포탈에 닿은 구성원부터 차례로 사라진다.
4. 마지막 구성원이 사라지면 페이드아웃하고, 그동안 다음 스테이지를 준비한다.
5. 준비가 끝나면 페이드인. 구성원은 제자리에 서서 다음 스테이지를 시작한다.

- 맵은 바꾸지 않고, 같은 맵에서 몬스터와 스테이지 상태만 새로 준비한다.
- 페이드는 기존 `ScreenFadeLogic`을 쓴다.

## 7. 성장·시간

- 전투 스테이지를 깰 때마다 레벨이 1 오른다 → 보스 전까지 Lv.10.
- 돌파: 전투 스테이지가 끝날 때마다 1번 (보스 제외 9번) + 물음표(저주받은 제단)로 추가.
- 자동 별 강화는 없다. 레벨업은 능력치만 올린다.
- 시간 목표: 층 하나 약 10분. 일반 전투 약 1분(웨이브 2개), 보스 약 1분 30초, 비전투 약 20~30초.
- 전투량이 지금(웨이브 20개)보다 줄어들므로 몬스터 능력치 증가 속도를 다시 맞춘다.

## 8. 장신구와 정비소

### 8-1. 슬롯

- 구성원마다 **반지 1칸 · 펜던트 1칸 · 귀고리 1칸**, 3명 합쳐 9칸.
- 성격: 반지 = 공격, 펜던트 = 생존, 귀고리 = 기술.
- 장착·교체는 정비소(와 물음표 '떠돌이 장인')에서만. 전투 중에는 바꿀 수 없다.
- 보관함은 없다. **장신구를 빼면 바로 판매되어 산 값의 절반을 돌려받는다 (확정).**
- 판이 끝나면 모두 사라진다.

- 기존 `SkillGradeTable`(색 포함)과 합칠 수 있는지 구현 때 확인한다.

### 8-4. 부가 옵션 목록

공격력 +5%, 공격 속도 +5%, 크리티컬 확률 +3%, 크리티컬 데미지 +10%, 최대 체력 +8%, 받는 피해 −4%, 준 피해의 1% 회복, 스킬 피해 +6%, 재사용 대기시간 −4%, 처치 메소 +8%, 정예·보스 피해 +8%.

- 기본 옵션과 같은 종류는 나오지 않는다.
- 레전더리의 두 줄은 서로 다른 종류.

### 8-5. 정비소 화면

- **왼쪽 (상점)**: 반지·펜던트·귀고리 1칸씩, 최대 3칸. 칸 테두리 색 = 등급.
  - 가격(초안): 처치 메소 × (일반 5 · 에픽 8 · 유니크 12 · 레전더리 20).
  - '다시 뽑기'(유료): 첫 비용 처치 메소 ×2, 누를 때마다 +50%. 정비소에 새로 들어오면 처음 비용으로 돌아간다.
- **오른쪽 (내 목록)**: 구성원 3명의 초상화 + 각각 반지·펜던트·귀고리 칸.
  - 산 장신구를 같은 종류 칸에 끼운다. 이미 끼워 둔 것이 있으면 그것은 판매(절반 환급)되고 바뀐다.
  - 구성원끼리 바꿔 끼울 수 있다.
  - 빼면 판매(절반 환급).
- **나가기**: 누르면 전투 포탈이 나타난다.

### 8-6. HUD

- 하단 구성원 패널마다 장신구 칸 3개(반지·펜던트·귀고리). 비면 빈 틀, 끼우면 아이콘 + 등급 색 테두리.
- 마우스를 올리거나 누르면 툴팁: 이름, 등급, 기본 옵션, 부가 옵션.

## 10. 구현 현황

### 1단계: 포탈 흐름 (2026-11-21, 메이커 실행 확인)

- 전투 스테이지 10개(보스 포함), 스테이지마다 웨이브 2개 (`RunConfig`: `StagesPerFloor=10`, `WavesPerStage=2`).
- 스테이지가 끝나면 레벨업·카드 처리 뒤 포탈 배치 (4장 규칙). 확인한 경우: 전투 9번 뒤 [정비소·물음표·보스], 비전투 다음 [보스]만.
- 포탈 클릭 → 구성원 이동(조작 캐릭터는 클라이언트가 위치 이동, 구성원 2·3번은 서버 이동 + 걷기 자세) → 닿은 순서대로 사라짐 → 페이드아웃 → 다음 스테이지 준비 → 페이드인.
- 거래 포탈은 기존 천사·악마 거래 화면으로 연결. 정비소·물음표는 아직 안내 문구만 띄우고 다음 포탈로 넘어간다.
- 보스 처치 → 층 클리어 결과 화면. 같은 판 결과 정산이 두 번 되지 않게 막음.
- 화면 제목: "1층 이름  스테이지 N/10 (정예/보스)".
- 코드: `Tower/TowerPortal.mlua`, `Models/Route/TowerPortal` 모델, `TowerRunManager`(OfferRoute·RequestPortal·TickWalk·LoadChosenStage 등), `TowerPlayer`(SetWalkPose·ClientWalkTo).

### 2단계: 돌파 규칙 (2026-11-21, 메이커 실행 확인)

- 판 시작 시 구성원 3명의 장착 스킬(5개씩)은 모두 배운 상태로 시작 (위력은 아웃게임 레벨). 판 시작 카드 없음.
- 자동 별 강화 제거. 레벨업은 능력치만 올린다.
- 전투 스테이지(1~9)가 끝날 때마다 돌파 1번: 카드 3장 = 구성원(직업)마다 장착 스킬의 남은 돌파 중 무작위 1장. 고를 돌파가 없는 구성원 칸은 다른 구성원 돌파로 채움. 다시 뽑기도 같은 규칙.
- 돌파를 고르면 바로 갈림길 포탈로 넘어간다.
- 코드: `TowerRunManager.RollPartyBreaks`, `RequestPick`(파티 돌파 분기), 각 전투 컴포넌트 `BeginRun`(SkillLv=1), `TarotLogic` 부제.

### 3단계: 정비소·장신구·HUD (2026-11-21, 메이커 실행 확인)

- 데이터 표: `AccessoryTable`(12종), `GradeTable`(공통 등급 6단계, 장신구는 4단계 사용), `AccessorySubTable`(부가 옵션 11종).
- 서버(`TowerRunManager`): 진열(종류별 1칸, 등급 확률·배율·부가 옵션), 구매 즉시 장착(끼워 둔 것은 판매), 빼면 판매(절반 환급), 구성원끼리 바꿔 끼기, 유료 다시 뽑기(처치 메소×2, +50%씩), 나가기 → 전투 포탈.
- 능력치 반영(낀 구성원만): 공격력·크리 확률·공격 속도·최대 체력·받는 피해 감소는 여신 효과와 같은 경로, 크리 데미지·스킬 피해·재사용 대기시간·정예/보스 피해·흡혈·쓰러질 때 버팀은 각 계산에 직접 연결. 처치 메소만 파티 전체.
- 화면: `ui/WorkshopUI` + `WorkshopUILogic` (왼쪽 진열대, 오른쪽 구성원 3명 × 반지·펜던트·귀고리 칸, 아래 상세·판매·나가기). 진열 카드를 고른 뒤 같은 종류 칸을 누르면 구매·장착, 끼운 장신구를 고른 뒤 다른 구성원 칸을 누르면 바꿔 끼기.
- HUD: 하단 구성원 패널마다 장신구 칸 3개(스킬 칸 아래) + 공용 툴팁 `AccTip` (`AccessoryHUDLogic`). 마우스를 올리면 표시, 누르면 고정/해제. 전투 HUD가 숨으면 툴팁도 닫힌다.
- 동기화: 장착·진열 정보는 직접 만든 문자열 형식(`AccessoryJson`, `ShopJson`). 빈 표는 JSON 변환이 안 된다(메이커 실측).
- 남은 부분: 구성원 초상화 칸은 자리만 있고 아바타를 아직 그리지 않는다(직업 이름으로 표시).
