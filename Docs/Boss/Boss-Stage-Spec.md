## 0. 한 줄 요약

> **층마다** 마지막 스테이지에 그 지역 원본 **필드보스**가 나온다(약점·반감만 있는 가벼운 관문). 필드보스를 처음 잡으면 지역 선택 화면 **보스 탭**에 그 보스의 **보스전**이 열린다. 보스전은 판 안 성장 없이 아웃게임 능력치로 싸우는 단판 공략전이고, 보스마다 **공략 포인트 1~2개**(약점 속성 편성, 보호막 깨기, 예고 패턴 대응, 칸 위치)를 둔다. 하루 3회, 단계 1~5.

## 1. 레퍼런스와 차용 요소

자세한 조사표와 출처는 [Stat-Redesign-Spec §1](../Combat/Stat-Redesign-Spec.md#1-레퍼런스-조사-모바일-게임). 보스 설계에 쓴 것만:

| 레퍼런스 | 차용 요소 | 우리 게임에서 |
|---|---|---|
| 붕괴: 스타레일 — 강인도·약점 격파 | 체력 위 흰 게이지, 약점 속성으로만 빨리 깎임, 깨지면 무력화+받는 피해 증가 | **보호막 게이지** (주니어 발록) |
| 승리의 여신: 니케 — 저지 원 | 큰 공격 전 "이걸 깨면 취소", 속성 우위 필요 | **예고 패턴 저지** (피아누스) |
| 블루 아카이브 — 공격/장갑 타입 | 보스마다 유리한 공격 타입 | 보스 **물리/마법 방어** 차이 (그리프·마뇽) |
| 쿠키런: 킹덤 — 진형·대상 | 보스가 특정 위치를 노림 | **칸 위치** 기믹 (그리프 날아오르기, 마뇽 브레스) |
| 메이플스토리 원본 | 지역 필드보스, 도감 속성 약점·반감·무효 | 보스 선정·속성 근거 |
| 메이플스토리M / 메이플 키우기 | 일일 보스 도전, 단계 해금, 첫 처치 보상 | **하루 3회 · 단계 1~5 · 첫 처치 다이아** |
| 에픽세븐 | 보스 특성을 아이콘 + 짧은 설명으로 | 공략 포인트 **아이콘 + 툴팁** |

## 2. 두 종류의 보스 — 역할 나누기

| | **필드보스** (층마다) | **보스전** (보스 탭) |
|---|---|---|
| 어디서 | 탑 판 안, 각 층의 **마지막 스테이지(15/15)** | 지역 선택 화면 **보스 탭** → 단독 입장 |
| 누구 | 그 층 지역의 원본 필드보스 ([표](Field-Boss-Map.md), 97층 중 38층). 없는 층은 대체 보스 | 5종 (§4). 이후 필드보스 중에서 추가 |
| 역할 | 층 관문 · 속성 시스템 **학습** | 핵심 재미 · 편성과 타이밍 **공략** |
| 전투 | 판 안 성장(레벨·돌파·장신구) 그대로. 웨이브 뒤 보스 1마리 | **판 안 성장 없음** — 캐릭터 레벨·장비·각인·펫·유물만. 보스 1 + 소환물 |
| 기믹 | 약점·반감·무효만 + 공통 예고 강타 1개 | 보스별 공략 포인트 1~2개 + 공통 예고 강타 |
| 난이도 | 기존 층 보스 수치(`BossHpMul 20`, `BossAtkMul 3`, `BossDefMul 3`) 유지 | 단계 1~5 (§6.2) |
| 실패 | 판 패배(기존 규칙) | 도전권 차감 없음, 다시 도전 가능 |
| 보상 | 기존 층 보상 그대로 (금색 메소 ×5, 깃털, 주문서, 큐브) | 금색 메소·경험의 서·큐브·주문서 + **첫 처치 다이아** (§7) |
| 해금 | 없음 (층에 들어가면 나옴) | 그 보스를 필드보스로 **처음 처치**하면 열림 |

- 필드보스는 "이 보스는 불에 약하구나"를 보여 주는 맛보기, 보스전은 그것을 **편성으로 풀어 보는** 본편이다.

## 3. 필드보스 (층마다)

### 3.1 배치 규칙
- 층 데이터 `FloorTable` 에 새 열 `FieldBossId`(MonsterTable id). [field_boss_map.csv](field_boss_map.csv) 의 `BossMobId`(없으면 `AltMobIds` 첫 번째)를 MonsterTable 행으로 추가해 연결한다.
- 층 마지막 스테이지(`StageKind == "boss"`, `Stage == StagesPerFloor`)의 마지막 웨이브 마지막 1마리 = 지금은 층 몬스터 중 무작위(`PickFloorInfo`) → **`FieldBossId` 가 있으면 그 몬스터**로 바꾼다. 앞 웨이브는 그대로 층 몬스터.
- 같은 보스를 여러 층이 함께 쓴다(예: 19·20층 엘리쟈, 23~25층 타이머). 같은 보스가 연속되면 뒤 층은 `BossHpMul` 은 층 비례로 커지므로 문제없다.

### 3.2 배경 (맵 가져오기 시험 반영)
- 탑은 `OrbisTower` 맵 하나로 돈다. 보스 스테이지 시작 때 `FloorTable` 새 열 `BossBgRUID`·`BossTileSetRUID` 가 있으면 그 배경으로 바꾸고(`ChangeBackgroundByTemplateRUID`, `FloorTileSet`), 다음 층으로 가면 원래대로.
- 두 RUID는 [표](Field-Boss-Map.md)의 `BossBgSourceMapId`(필드보스가 나오는 원본 맵)를 메이커로 가져와 읽는다(§3 of Field-Boss-Map). 메이커 목록에 없는 맵이거나 대체 보스면 **빈칸 = 층 배경 그대로**.
- 보스 전용 맵·원본 맵 통째 가져오기는 쓰지 않는다(좌표·정렬 레이어·필드보스 미포함 문제).

### 3.3 필드보스 기믹 (공통 1개)
- **예고 강타**: 12초마다 보스 머리 위에 빨간 느낌표 + 바닥 띠 2초 → 1번 칸 캐릭터에게 보스 공격 ×2.5 (필중). §5.4 공통 대응(방어 버튼)으로 줄일 수 있다.
- 속성 상성은 MonsterTable `Elem` 그대로(도감 근거 있는 보스: 주니어 발록·피아누스·그리프·마뇽).

## 5. 보스별 공략 포인트

모든 보스전 공통: 우리 편 칸 1~3, 보스는 **몬스터 1칸**에 서고 크기 `BossScale 1.5`. 제한 시간 180초(넘으면 실패). 공통 예고 강타(§3.3) 포함.

### B1 머쉬맘 — "졸개부터 치워라" (입문)
- 공략 포인트 1 — **버섯 소환 + 보호 오라**: 20초마다 주황버섯 2마리를 몬스터 2·3칸에 소환. 소환물이 **하나라도 살아 있으면 머쉬맘 받는 피해 −60%**(머쉬맘 머리 위 초록 방패 아이콘). → 광역(히어로·보우마스터) 또는 사거리 2~3칸 직업이 유리.
- 약점 없음, 물리/마법 방어 같음 → 속성 고민 없이 기믹만 익히는 입문 보스.
- 툴팁: "버섯이 있으면 단단해집니다"

### B2 주니어 발록 — "성으로 장벽을 깨라" (보호막)
- 원본 속성: 독 **무효**, 성 **약점** → 나이트로드 독 지속 피해가 통하지 않고 비숍이 핵심.
- 공략 포인트 1 — **암흑 장벽(보호막 게이지)**: 시작 시와 체력 50%에 생성. 게이지 = 보스 최대 체력의 15%. **성 속성 피해는 100%**, 다른 속성 25%만 게이지를 깎는다(스타레일 강인도). 게이지가 있는 동안 체력은 깎이지 않음(피해는 게이지로).
  - 깨지면 **그로기 5초**: 보스 공격 멈춤, **받는 피해 +50%**.
  - 25초 안에 못 깨면 "장벽 폭발": 파티 전체 최대 체력 30% 피해(필중) 후 게이지 다시 가득.
- 방어: 물리 방어 30 / 마법 방어 0 (악마형 — 물리는 덜 아픔, 마법 유리).
- 툴팁: "성 속성으로 장벽을 깰 수 있습니다 · 독이 통하지 않습니다"

### B3 피아누스 — "해일을 불로 끊어라" (예고 저지)
- 원본 속성: 불 **약점** → 보우마스터(불 스킬) 핵심.
- 공략 포인트 1 — **해일 예고 저지**: 15초마다 4초 예고(보스 위 파란 원 + 바닥 띠 + 저지 게이지). 예고 동안 **저지 게이지**(보스 최대 체력 5%)를 깎으면 해일 취소 + 그로기 3초. **불 속성은 2배로** 깎는다(니케 저지 원).
  - 실패하면 해일: 파티 전체 최대 체력 40% 피해(필중) + 3초 공격 속도 −30%.
- 공략 포인트 2 — 방어 버튼(§5.4)으로 해일 피해를 줄여 버티는 것도 가능 → 불이 없어도 클리어할 길을 남긴다.
- 방어: 물리 0 / 마법 20 (어류형, 설계값).
- 툴팁: "큰 기술 전에 피해를 모으면 막을 수 있습니다 · 불에 약합니다"

### B4 그리프 — "날면 멀리서, 독으로" (칸·회피)
- 원본 속성: 독 **약점**, 전기(번개) **반감** → 나이트로드 독 유리, 바이퍼 번개 불리.
- 공략 포인트 1 — **날아오르기**: 18초마다 6초 동안 공중으로 올라 몬스터 **2칸**으로 이동. 그동안 **사거리 1칸 직업(히어로·바이퍼)은 공격 불가**, 사거리 2~3칸(비숍·나이트로드·보우마스터)만 닿음 (쿠키런 진형 차용, 기존 칸 전투 `CanReach` 그대로 활용).
- 공략 포인트 2 — **높은 회피**: 회피 40 → 물리는 명중이 낮으면 자주 빗나감. **마법은 필중**이라 비숍 유리. 명중 망토 성장의 쓰임새.
- 방어: 물리 0 / 마법 0.
- 툴팁: "날아오르면 가까이서 칠 수 없습니다 · 회피가 높습니다 · 독에 약합니다"

### B5 마뇽 — "불은 빼라" (반감 피하기 + 위치)
- 원본 속성: 불 **반감**, 얼음 **약점**. 지금 5직업은 얼음이 거의 없다 → **약점 맞추기보다 반감 피하기**가 숙제(보우마스터 불 스킬이 반감). 이후 얼음 직업·장신구가 생기면 보상받는 구조.
- 공략 포인트 1 — **화염 브레스(뒤 칸 노림)**: 14초마다 3초 예고 후 **우리 편 3번 칸(맨 뒤)** 에 큰 피해(최대 체력 55%, 필중). 뒤에 약한 딜러를 두면 위험 → 3번 칸에 체력 높은 캐릭터를 두는 편성 고민. 방어 버튼으로 줄일 수 있음.
- 공략 포인트 2 — **분노**: 체력 30% 이하에서 공격 간격 ×0.67 (빨라짐). 마지막 구간을 빨리 넘기라는 신호.
- 방어: 물리 30 / 마법 30.
- 툴팁: "불에 강합니다 · 맨 뒤를 노립니다 · 체력이 낮으면 사나워집니다"

### 5.4 공통 수동 조작 — 방어 버튼 하나만
- 자동 전투 게임이라 수동 조작은 **보스전·필드보스 HUD의 버튼 1개**만 둔다.
- 예고(빨간 띠)가 떠 있는 동안 누르면 그 패턴 피해 **−70%**, 쿨타임 20초. 예고가 없을 때 누르면 아무 일 없음(쿨타임도 안 돎). 비활성 상태는 Disabled 이미지 + 실제 입력 차단.
- 피아누스 해일·마뇽 브레스·발록 장벽 폭발·공통 예고 강타 모두 적용.

## 6. 보스전 규칙

### 6.1 진행
1. 보스 탭에서 보스·단계 선택 → [도전] → 로비 서버가 검사(해금·도전권·단계 해금) → `OrbisTower` 로 이동.
2. 탑에서 `RunMode = "boss"` 로 시작: 층·포탈·상점·거래·판 안 레벨업·돌파·장신구 **없음**. 편성 3인 + 아웃게임 능력치. 펫은 동행.
3. 파티 입장 걷기(기존 `BeginStageEntry`) → 보스 배경으로 교체 → 보스 등장.
4. 보스 처치 = 클리어 → 결과 팝업(기존 `ResultPopup` 재사용, 보스 모드 문구). 전멸·시간 초과 = 실패.
5. **도전권은 클리어할 때만 1장 차감.** 실패는 무료(부담 없이 공략 시도).

### 6.2 단계와 수치
- 단계 1~5. 단계 N+1은 단계 N 클리어 시 열림.
- 보스 기본 수치는 "해금 층의 층 보스" 수치를 기준으로 한다: `체력 = 그 층 보스 체력 × HpMul`, `공격 = 그 층 보스 공격 × AtkMul`. 판 안 성장이 없으므로 1단계는 층 보스보다 약하게.

| 단계 | HpMul | AtkMul | 비고 |
|---|---|---|---|
| 1 | 0.6 | 0.6 | 해금 직후 깰 수 있게 |
| 2 | 1.2 | 0.9 | |
| 3 | 2.4 | 1.3 | 기믹을 풀어야 깨짐 |
| 4 | 4.8 | 1.8 | |
| 5 | 9.6 | 2.5 | 엔드 콘텐츠 |

- 수치는 잠정. **밸런스 측정은 하지 않는다**(사용자가 직접 플레이하며 조정, 01-Agent-Rules 테스트 범위).

### 6.3 도전권
- **하루 3회 (모든 보스 공용)**. 매일 0시(UTC+9) 초기화. 저장은 `PlayerBoss`.
- 에너지(지역 입장 에너지)는 쓰지 않는다 — 두 콘텐츠를 분리해 보스전이 파밍을 막지 않게.

## 11. 확인 못 한 것

- **원본 몬스터 수치 없음:** SSD `Mob/Mob.xml` 에 몬스터별 `info`(isBoss·level·PADamage·MADamage·PDDamage·MDDamage·acc·eva·elemAttr)가 없다(BossPattern·QuestCountGroup만 있음). 속성은 도감(MonsterBook) 문구, 레벨도 도감, 보스 여부는 보스 체력바 목록으로 대신했다. **방어·회피·체력 배율은 설계값**이다. 예전 다운로드 폴더는 쓰지 않았다.
- 피아누스 레벨 "알 수 없음"(도감 원문).
- 보스 배경 RUID(`BossBgRUID`)는 메이커에서 원본 맵을 가져와 읽어야 해서 비어 있다(B1).
- 머쉬맘 원본 그림 폴더에 `stand` 가 없어 `move/0` 으로 비교했다(MSW 팩에는 stand 있음).
- 레퍼런스 중 메이플스토리M·에픽세븐·쿠키런은 웹 출처 없이 작성자 지식.

## 12. 사용자에게 물을 것

1. 보스전 첫 처치 **다이아 지급**(단계별 50~200)을 넣을지 — 마스터 명세의 다이아 지급처 외 추가.
2. 도전권 **하루 3회 공용**, **클리어 시에만 차감** 이 괜찮은지.
3. 수동 조작을 **방어 버튼 1개**로 두는 것이 괜찮은지(아예 없애고 편성만으로 풀게 할 수도 있음).
4. 보스 탭 열림 조건: 3층(머쉬맘) 처치 vs 계정 레벨 해금표(`UnlockTable`)에 넣기.
