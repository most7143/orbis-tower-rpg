## 1. 근거 자료와 판정 방법

모두 외장 SSD `/Volumes/P7/MapleStoryWorld/최신메이플데이터` 기준이다.

| 항목 | 근거 파일 | 비고 |
|---|---|---|
| 층의 원본 맵 | `Docs/FloorPlan_Draft.csv`의 `MapId` | 층마다 실제로 쓰는 원본 필드 맵 |
| 맵에 나오는 몬스터 | `Etc/Etc/_root.xml`의 `MapObjectInfo.img`(맵별 몬스터 목록) + `Map/Map/Map/Map0~9.xml`의 `life`(type=m) | 두 목록을 합쳤다. 고전 필드보스(머쉬맘·스텀피 등)는 `life`에 없고 `MapObjectInfo`에만 있다 (맵 가져오기 시험 결과와 일치) |
| 보스 여부 | `UI/UI.xml`의 `UIWindow2.img/MobGage/Mob` (보스 체력바가 붙는 몬스터 1,539종) | **주의:** SSD의 `Mob/Mob.xml`에는 몬스터별 `info`(isBoss·level·elemAttr·PADamage 등)가 들어 있지 않다(BossPattern·QuestCountGroup만 있음). 그래서 `isBoss` 대신 "보스 체력바 등록(MobGage)"을 보스 판정으로 썼다. CSV `BossCheck` 열 = `MobGage` |
| 레벨·속성 | `_Strings/MonsterBook.xml`의 `episode` (몬스터 도감: "레벨 : Lv.N", "특이사항 : …속성 공격에 약함") | 도감에 없는 몬스터(대체로 빅뱅 이후 지역)는 레벨 "미상" |
| 이름 | `_Strings/Mob.xml`, `_Strings/Map.xml` | |

**같은 지역 판정:** 층의 원본 맵과 (거리 이름이 같고 맵 번호 앞 3자리가 같거나) 맵 번호 앞자리(고전 지역 5자리, 3억 번대 이후 7자리)가 같은 맵. 맵 번호 9억 번대(이벤트·인스턴스·퀘스트 전용)는 뺐다.

**대표 보스 고르기:** 같은 지역 보스가 여럿이면 층 몬스터 최고 레벨과 가장 가까운 보스. 아쿠아리움·리프레·엘나스는 맵 위치에 맞춰 직접 골랐다(26·27 세르프, 28·29 피아누스, 35 설산의 마녀, 36 리치, 37 스노우맨, 38 그리프, 39 마뇽, 40 레비아탄). 65·66 블랙헤븐은 같은 지역 이야기 맵(블랙헤븐 갑판)의 게오르크를 넣었다.

**대체 후보 고르기 (필드보스 없음):**
- 층 몬스터 레벨을 알면: 원본 필드 맵에 나오는 보스 중 층 몬스터 최고 레벨 ±10 안에서 가까운 2종. 없으면 가장 가까운 2종.
- 층 몬스터 레벨을 모르면(도감 미수록): 앞뒤 층의 필드보스.

- 97층 중 **38층**에 원본 필드보스가 있다 (보스 종류로는 27종).
- 필드보스가 없는 층은 주로 오르비스탑·에오스 탑(탑 내부 층), 판타스틱 테마파크, 책장 너머의 세계, 파르템, 기사단·커닝 뒷골목, 아케인리버(츄츄~에스페라 이후)다.
- 아케인리버 이후 지역은 원본에도 필드보스가 거의 없고(레이드·주간 보스 중심), 도감 레벨도 없다 → 대체 보스는 앞뒤 층 보스 또는 보스 탭 보스를 쓴다.

## 3. 보스 층 배경 — 원본 맵 가져오기 시험 결과 반영

시험 결과([Map-Import-Test.md](Map-Import-Test.md)): 메이커 `maker_import_maplestory_map` 으로 원본 맵 통째 가져오기는 **된다**. 하지만 최신 원본 맵 `life` 에는 필드보스가 거의 없고(예외 103030300 다일), 가져온 맵은 좌표·정렬 레이어가 탑 칸 전투와 맞지 않는다.

**채택 방식 (권장):**
- 탑은 지금처럼 **`OrbisTower` 맵 하나**로 돈다. 보스 층(층 마지막 스테이지)도 같은 흐름.
- 이 표의 `BossBgSourceMapId`(필드보스가 나오는 원본 맵)에서 **배경 템플릿 RUID·타일셋 RUID만 빌려** 층 데이터(`FloorTable` 새 열 `BossBgRUID`·`BossTileSetRUID`)에 넣고, 보스 스테이지 시작 때 `ChangeBackgroundByTemplateRUID` + `FloorTileSet` 교체로 바꾼다.
- 보스는 기존 칸 전투 소환(`SpawnByModelId(..., self.Entity)`)으로 배치한다. 보스 전용 맵은 쓰지 않는다.
- RUID 얻는 법: 메이커 `maker_list_maplestory_maps` 를 **원본 ID로 검색**(목록 이름이 영어라 한글 검색 안 됨) → 가져오기 시험용 맵에서 `BackgroundComponent.TemplateRUID`·`TileMapComponent.TileSetRUID` 읽기. 메이커 목록에 없는 맵(예: 200010303 엘리쟈의 정원)은 **그 층의 기존 배경 그대로** 쓴다.

| 경우 | 배경 | 보스 |
|---|---|---|
| 필드보스 있음 + 보스 맵이 메이커 목록에 있음 | `BossBgSourceMapId` 의 배경·타일셋 | 표의 필드보스 |
| 필드보스 있음 + 보스 맵이 목록에 없음 | 층 기존 배경(`FloorTable.BgRUID`) | 표의 필드보스 |
| 필드보스 없음 | 층 기존 배경 (대체 보스의 원래 맵 `AltBgSourceMapIds` 는 참고용, 쓰지 않는 것을 기본으로) | 대체 후보 1번 |

**보스 판정 근거 다시 정리:** 필드보스는 맵 `life` 가 아니라 ① `Etc` 의 `MapObjectInfo.img`(원본 클라이언트가 월드맵·도감에 쓰는 "맵에 나오는 몬스터" 목록 — 고전 필드보스가 여기 남아 있다) ② 보스 체력바 목록(MobGage) ③ 몬스터 도감 레벨로 정했다. SSD `Mob.xml` 에 `isBoss`·`level` 값이 없어 ②③으로 대신했다(CSV `BossCheck`, `BossSourceBasis` 열).

**CSV 열 설명:** `BossMapId`·`BossBgSourceMapId` = 필드보스가 나오는 원본 맵(배경 빌릴 맵), `AltBgSourceMapIds` = 대체 후보 보스의 원래 맵, `BossSourceBasis` = 근거(`MapObjectInfo` 또는 `Map.life`), `ElemNote` = 도감 속성 특이사항.

## 5. 확인 못 한 것

- 원본 몬스터 `info`(isBoss·level·elemAttr·PADamage·MADamage·acc·eva)가 SSD 데이터에 없다. 보스 판정은 보스 체력바 목록, 레벨·속성은 몬스터 도감 문구로 대신했다. 원본 `Mob/<ID>.img` 수치가 들어간 데이터를 SSD에 추가하면 CSV의 `BossLevel`·`ElemNote`를 다시 뽑아 검증할 것.
- `MapObjectInfo`는 "그 맵에 나오는 몬스터 목록"이라 보스가 일정 시간마다 나오는지(리젠 주기)는 알 수 없다.
- 리소스 팩(MSW) 존재 여부는 보스 탭 5종만 확인했다. 필드보스 38층분은 구현 단계에서 `msw-search`로 확인한다.
