## 1. 한눈에 보기

| 항목 | 지금 | 2인 편성 |
|---|---|---|
| 전투 인원 | 플레이어 캐릭터 1명 | **메인 1명 + 동료 1명** (둘 다 자동 전투) |
| 역할 조합 | — | 근거리 범위 딜(히어로), 케어(비숍), 원거리 단일 딜(나이트로드) 중 2개 |
| 효과 대상 `Party` | 솔로에서는 자신 | **두 캐릭터 모두** (멀티 규칙과 같음) |
| 몬스터가 노리는 대상 | 플레이어 | 위협 1위 (가까울수록 위협 증가) |
| 체력 | 1개 | 캐릭터마다 따로. **둘 다 쓰러지면 실패** |
| 마나 | 1개 | 캐릭터마다 따로 |
| 판 안 레벨 | 1개 | **공유 레벨 1개**. 카드는 두 캐릭터의 스킬에서 나옴 |

**왜 좋은가**
- 솔로에서도 역할 조합을 연습할 수 있다. 멀티에 들어가기 전 직업을 익히는 단계가 된다.
- 비숍의 파티 효과가 솔로에서도 의미가 생긴다. 지금 초안에서 가장 큰 약점이던 비숍 솔로 화력 문제가 풀린다.
- 나이트로드의 '몰리면 위험' 약점을 앞에 선 동료가 메운다.

## 2. 편성

| 항목 | 제안 | 이유 |
|---|---|---|
| 편성 칸 | 메인 1 + 동료 1 | 화면과 연출 부담이 가장 적은 인원 |
| 같은 직업 두 명 | **불가 (확정, 2026-11-18)** | 역할 조합을 강제해 멀티 연습이 되게 함 |
| 동료 해금 | **처음부터 2인 편성** (확정, 2026-11-18). 1인 전투 구간은 없음 | 시작 시 히어로·비숍 둘 다 지급 (확정). 나이트로드는 이후 해금 |
| 변경 시점 | 로비에서만. 판 안에서는 못 바꿈 | |
| 위치 | 근거리 직업이 앞, 원거리 직업이 뒤 (자동) | 줄 선 몬스터 구조와 맞음. 히어로+비숍이면 히어로가 앞 |
| 메인과 동료의 차이 | 메인은 결과창·아바타 대표·화면 중심. **전투 능력은 같다** | 동료를 약하게 만들면 2인 편성 의미가 없음 |

**원거리 둘(비숍+나이트로드)일 때**
- 앞에 설 사람이 없다. 몬스터가 두 사람 모두에게 붙는다.
- 자동 배치 규칙으로 체력이 높은 쪽이 앞에 선다. 비숍 ×1.0이 나이트로드 ×0.85보다 높아 비숍이 앞에 선다.
- 가장 어려운 조합이 되는데, 의도한 것이다.

## 3. 전투 규칙

### 3.1 공격과 스킬

- 두 캐릭터는 각자의 **기본 공격 → 스킬 선택 규칙**(히어로 규칙서 §3)을 따로 돈다.
- 각자 자기 마나와 자원을 쓴다. 콤보·성수·표식도 각자 따로다.
- **표식은 몬스터에 쌓인다.** 동료의 공격은 표식을 쌓지 않는다. 대신 약점 노출 상태의 치명타 보너스는 동료도 받는다.
- 나이트로드 '단일 보정' 판정은 그 공격이 맞힌 몬스터 수로 한다. 동료와 관계없다.

### 3.2 몬스터 공격 대상

- 앞 몬스터와 줄 선 몬스터는 **위협 1위 캐릭터**를 공격한다.
  - 위협은 피해·회복·거리·직업 배율로 계산한다 (역할 문서 §3.1).
- 원거리 딜러가 딜을 몰아 넣으면 공격이 넘어온다.
  - 나이트로드는 다크 사이트로 위협을 초기화한다.
  - 비숍은 매직쉘로 버틴다.
- 엘리트·보스 패턴 공격은 위협과 관계없이 범위·무작위로 대상을 정한다.

### 3.3 쓰러짐과 부활

| 상황 | 규칙 |
|---|---|
| 한 명이 쓰러짐 | 15초간 '쓰러짐' 상태. 남은 한 명이 계속 싸운다 |
| 자동 부활 | 남은 캐릭터가 **웨이브를 하나 끝내면** 쓰러진 캐릭터가 체력 30%로 일어난다 |
| 비숍 리저렉션 | 즉시 부활 (헤븐즈 도어 돌파) |
| 둘 다 쓰러짐 | 실패 → 결과창 |

- 멀티의 '곁에 3초 서 있기' 부활은 솔로에서 조작이 없으므로 '웨이브 끝 자동 부활'로 바꾼다.

### 3.4 몬스터 수치

- 화력이 두 배가 되므로 **몬스터 체력 ×1.7**로 시작한다. 공격력은 그대로 두고 위협 대상 한 명에게 몰리게 한다.
- 최종 배율은 시뮬레이션으로 정한다.

## 4. 성장과 레벨업 카드

### 4.1 아웃게임

| 항목 | 규칙 |
|---|---|
| 직업별 스킬 | 직업마다 따로 뽑고 키운다 (히어로 15종, 비숍 15종, 나이트로드 15종) |
| 장착 | 직업마다 5칸. 동료로 나가도 자기 장착 5종을 쓴다 |
| 고유 패시브 | 직업마다 따로 (콤보 어택, 홀리 워터, 마크 오브 나이트로드) |
| 장비·계정 능력치 | 계정 공통. 두 캐릭터 모두에게 적용 |
| 스킬북 | 직업 공통 재화 (어느 직업에 쓸지 고름) |

### 4.2 판 안 (레벨업 카드)

- **공유 레벨 1개 (확정, 2026-11-18).** 레벨업마다 카드 3장 중 1장을 고른다.
- 카드 후보는 두 캐릭터의 장착 스킬 **10종**이다.
- 카드에는 **캐릭터 얼굴(직업 아이콘)을 표시**해 누구의 스킬인지 보이게 한다.
- 스킬 하나가 Lv.9까지 가려면 8장이 필요하다. 10종을 다 키울 수는 없다.
  - 그래서 "메인을 깊게 키울지, 둘을 고르게 키울지"가 판마다 고민거리가 된다.
- 판 안 최대 레벨과 필요 경험치는 1인 기준을 유지하되, 카드가 모자라면 레벨 상한을 조정한다 (시뮬레이션 후 결정).

**새로 가능해지는 재미**
- **연계 카드 (선택 사항):** 두 직업 조합에서만 나오는 카드. 예시:
  - 히어로+비숍: 히어로가 콤보를 쓸 때 비숍 성수 +1
  - 히어로+나이트로드: 히어로 자상 5중첩이면 표식 가득
  - 비숍+나이트로드: 신성 낙인 대상에게 나이트로드 치명타 +15%

## 5. 멀티와의 관계

| 항목 | 솔로 2인 편성 | 멀티 (보스·특정 콘텐츠) |
|---|---|---|
| 유저 수 | 1 | 2~4 (확정 필요) |
| 캐릭터 수 | 2 (메인+동료) | **유저당 메인 1명** (확정, 2026-11-18) |
| 효과 대상 `Party` | 두 캐릭터 | 모든 유저의 캐릭터 |
| 부활 | 웨이브 끝 자동 | 곁에 3초 서 있기 |
| 레벨업 카드 | 공유 레벨, 10종 후보 | 각자 레벨, 자기 5종 후보 |

- 멀티에서 동료를 빼는 이유 (확정)
  - 4인 × 2명 = 8명이면 화면이 혼잡하다.
  - 다른 유저의 역할이 동료로 대체되면 같이 할 이유가 줄어든다.
- 2인 편성 전투 로직을 만들면 멀티의 대부분(파티 대상, 위협, 쓰러짐)을 그대로 쓸 수 있다. **2인 편성이 멀티의 1단계**가 된다.

현재 전투는 **캐릭터 1명을 전제**로 짜여 있다.

| 영역 | 지금 | 바꿀 것 |
|---|---|---|
| `TowerRunManager` | 체력·마나·레벨·몬스터 공격 타이머를 매니저 하나가 관리. 플레이어 위치 `PlayerPos` 하나 | 캐릭터별 상태(체력·마나·쓰러짐)를 목록으로. 위치 2개(앞·뒤). 몬스터 공격 대상 선택(위협) |
| `HeroCombatLogic` | 히어로 전용, 플레이어 1명 기준 (`Has()` 돌파 분기) | 캐릭터별 인스턴스로 동작. 직업 공통 + 직업 특수 모듈로 분리 (히어로 규칙서 §9.4) |
| 동료 캐릭터 | 없음 | 아바타를 가진 **비플레이어 개체** 모델 (코스튬·직업 무기·동작 재생) |
| HUD | 체력·마나·스킬 칸 1세트 | 동료 체력·마나 작은 표시, 스킬 칸 2줄(또는 메인만 크게) |
| 레벨업 카드 UI | 스킬 5종 | 10종 후보, 직업 아이콘 표시 |
| 로비 | 장착 1세트 | 편성 화면(메인·동료), 직업별 스킬 창 |
| 저장 데이터 | 히어로 기준 | 직업별 스킬·장착·패시브, 편성 정보 |

### 6.1 진행 순서 제안

> **선행 조건:** 처음부터 2인 편성이고 같은 직업 2명이 금지되므로, 출시 전에 **두 번째 직업(**비숍**)이 반드시 완성**되어야 한다. 그 전까지 개발 빌드는 히어로 2명으로 테스트한다.

1. **전투 로직 다인화:** 히어로 2명(테스트용)으로 2인 전투가 돌아가게 만든다. 같은 직업 금지는 테스트 동안 풀어 둔다.
2. **위협·쓰러짐·웨이브 끝 부활:** 몬스터 대상 선택과 실패 조건.
3. **비숍 구현 (확정):** 스킬 표, 동작, 원거리 기본 공격, 파티 회복·버프. 나이트로드는 그다음.
4. **편성 UI·HUD·카드 UI:** UI 디자인 기준 문서(`Docs/UI-Design-System.md`)를 따른다.
5. **수치 조정:** 몬스터 체력 배율, 레벨 상한.
6. **멀티:** 2인 편성 로직을 유저 여러 명으로 확장.

## 기본 공격·스킬 시전 규칙 (사용자 확정 2026-11-21)

- **기본 공격 쿨타임 3초** (`TowerRunManager.AttackCooldown`). 무기 공격 속도·속도 보너스로 줄어든다: `3 ÷ (무기 속도 × (1 + 속도% / 100))`.
- 쿨타임은 몬스터가 걸어오는 동안에도 돈다. 맨 앞 몬스터가 사거리 칸 안이면 쿨타임이 끝난 즉시 공격한다.
- **스킬은 기본 공격과 별개로 시전**: 마나·쿨타임·사거리가 모두 되면 기본 공격 쿨타임을 기다리지 않고 계속 시전한다 (`ActorTryAttack` → 각 직업 `RollSkillCasts`). 동작 중에는 다음 공격·스킬을 시작하지 않는다 (`BasicMotionTime` 0.5초, 동작 없는 스킬 간격 `SkillCastGap` 0.3초).
- 기본 공격 적중 시 얻는 마나·콤보·확률 발동은 기존과 같다 (기본 공격에만 붙음).

## 칸 전투 (사용자 확정 2026-11-21)

- 우리 편 1·2·3칸(서는 자리 1번 -1.0 / 2번 -1.45 / 3번 -1.9), 몬스터 1·2·3칸(x = -0.4 / 0.6 / 1.6, 칸 간격 `CellWidth` 1.0).
- **사거리 = 칸 수.** 우리 편 사거리 N이면 몬스터 1~N칸에 있는 맨 앞 몬스터를 공격한다. 우리 편이 몇 번 칸에 서 있는지는 사거리에 영향을 주지 않는다.
  - 직업 사거리 (`JobRanges`, 임시): 히어로 1, 바이퍼 1, 비숍 2, 나이트로드 2, 보우마스터 3.
- **몬스터는 자기 사거리 칸에 도착해 멈춘다.** 오른쪽에서 걸어와 3칸 → 2칸 → 1칸 구간을 지나므로, 원거리 캐릭터가 다가오는 몬스터를 먼저 견제한다.
  - 몬스터 사거리 = 몬스터 데이터 `AttackRange`. 웨이브의 원거리 자리(`RangedRatio`) 몬스터는 최소 2칸.
  - 같은 칸에 여러 마리가 오면 `MeleeGap` 간격으로 조금씩 떨어져 서지만 판정은 같은 칸이다.
  - 다음 맨 앞 몬스터 = 가장 가까운 칸(사거리가 짧은) 몬스터, 같은 칸이면 먼저 온 몬스터.
- **몬스터 공격**: 자기 칸에 도착한 몬스터가 공격하고, 사거리 N이면 우리 편 1~N번 중 위치 확률(1번 50% · 2번 35% · 3번 15%, 후보끼리 비율 재조정)로 대상을 고른다 (`PickTarget`, 기존 로직 유지).
- **안전장치**: 맨 앞 몬스터가 자기 칸에 도착했는데 살아 있는 우리 편 누구의 사거리에도 닿지 않으면 1칸으로 다가온다 (`PullIfUnreachable`). 근거리만 남았을 때 전투가 멈추지 않게 한다.
- **스테이지 입장**: 전투 스테이지가 시작되면 구성원이 자기 자리보다 `EntryDist`(3.0) 왼쪽에서 `EntryWalkSpeed`(2.2)로 걸어 들어와 자리를 잡는다. 모두 도착하면(최대 4초) 몬스터가 나오며 전투가 시작된다 (`BeginStageEntry` / `TickEnter`, 상태 `ENTER`). 판 첫 스테이지와 포탈로 고른 전투 스테이지 모두 적용.
