## 3. 핵심 루프 (한 판)
```
판 시작(1층, Lv1, 메소 0)
  → 몬스터 등장(우측) ⇄ 플레이어(좌측) 자동 공격 주고받기
  → 몬스터 처치 → 메소 + 경험치 획득 → (레벨업 시 스킬 해금)
  → 다음 층으로 (층수 +1, 더 강한 몬스터)
  → 아래 탭에서 메소로 공격력·체력·스킬 강화 (전투는 계속 진행)
  → … 반복 …
  → 플레이어 HP 0 → 패배: 도달 층 결과 표시 → 판 초기화 → 다시 1층부터
```

## 4. 핵심 시스템
- **전투**: 플레이어·몬스터 모두 `공격력 / 최대 HP / 공격 속도(초당 공격 수)` 보유. 공격 타이밍마다 상대 HP 감소. 공격 모션 + 데미지 숫자 + 피격 연출.
- **층(스테이지)**: 층 N의 몬스터 HP·공격력 = 기본값 × 성장 계수^(N−1) (잠정 계수 1.12). 층 범위마다 몬스터 외형 교체 (예: 1~5층, 6~10층 …).
- **보상**: 처치 시 메소(층에 비례해 증가) + 경험치.
- **레벨**: 판 안 레벨. 경험치 누적 → 레벨업 → 기본 능력치 소폭 상승 + 정해진 레벨에서 스킬 해금 (예: Lv3, Lv6, Lv10).
- **능력치 강화(메소)**: 공격력 / 최대 HP (필요하면 공격 속도). 강화할수록 비용 증가 (잠정: 비용 = 기본 × 1.15^단계).
- **스킬(메소 강화)**: M1은 3종. 해금되면 쿨타임마다 자동 발동 (예: 강타 — 큰 단일 데미지, 회복 — HP 회복, 연속 공격 — 짧은 시간 공격 속도 증가). 메소로 스킬 레벨을 올리면 효과 증가.
- **패배/초기화**: HP 0 → 결과(도달 층·획득 메소) 표시 → 판 상태 전부 초기화 → 1층부터 재시작. 최고 도달 층은 저장해 표시.
- **UI (아래 2/3, 탭 4개)**: ① 캐릭터 정보 (레벨·경험치·능력치·현재 층·최고 층) ② 능력치 강화 ③ 스킬 강화 ④ 장비 (M1은 "준비 중" 틀만). 위쪽 전투 화면에는 층 표시, 양쪽 HP 바, 보유 메소 표시.
